> [!NOTE]
> 这是重构前的 1.x 版本（当时名为 AuthX）。从 1.x 升级请参阅 [升级与旧版本迁移](/start/upgrade/)。

## 修复

- 新建内容没有给出明确的提示信息
- 菜单管理选择分类后分页无法使用
- 新建菜单选择接口类型后父菜单类型没有根据选择的类型修改
- 新建菜单页面选择框与主题不协调
- 页面未进行国际化完整
- 左侧菜单无法进行单菜单跳转问题
- 添加到系统接口中的路径地址无法授权提示 `this is not active token`

## 新功能

- 审计日志类型
- 分配用户权限功能
- 审计日志
- 用户管理
