> [!NOTE]
> Esta é uma versão 1.x anterior à reconstrução (na época chamada AuthX). Para atualizar a partir da 1.x, consulte [atualizar e migrar de versões antigas](/pt-br/deploy/upgrade/).

## Correções

- Ao criar conteúdo, não era exibida uma mensagem de orientação clara
- No gerenciamento de menus, a paginação deixava de funcionar após selecionar uma categoria
- Ao criar um menu, depois de escolher o tipo de interface, o tipo do menu pai não era alterado conforme o tipo escolhido
- Na página de criação de menus, o campo de seleção não combinava com o tema
- A internacionalização da página estava incompleta
- Problema: o menu lateral não permitia navegar para um menu individual
- Ao adicionar um endereço de rota à interface do sistema, não era possível conceder permissão; aparecia a mensagem `this is not active token`

## Novas funções

- Tipos de registro de auditoria
- Função de atribuição de permissões a usuários
- Registro de auditoria
- Gerenciamento de usuários
