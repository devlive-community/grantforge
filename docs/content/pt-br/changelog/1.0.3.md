> [!NOTE]
> Esta é uma versão 1.x anterior à reconstrução (na época chamada AuthX). Para atualizar a partir da 1.x, consulte [atualizar e migrar de versões antigas](/pt-br/deploy/upgrade/).

## Correções

- A mensagem de orientação do menu não correspondia ao menu
- Os dados paginados ultrapassavam a largura da página
- Ao criar um usuário, não havia resposta
- Erro de compilação
- A função do painel lateral esquerdo não funcionava e a página ficava inteiramente em branco

## Novas funções

- Adição da função de pequenos utilitários JSON
- Novo módulo de estatísticas, com dados de usuários e registros do painel
