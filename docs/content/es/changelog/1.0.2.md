> [!NOTE]
> Esta es una versión 1.x anterior a la reescritura (entonces se llamaba AuthX). Para actualizar desde 1.x, consulta [Actualización y migración desde versiones antiguas](/es/deploy/upgrade/).

## Correcciones

- No se podían asignar funciones de menú
- Aparecía una página en blanco en la parte superior
- En la gestión de registros no se podía ver el detalle de una entrada concreta
- El método de solicitud del menú tenía datos duplicados
- Al crear un menú se configuró un icono, pero el icono del menú de página única no cambiaba
- Al crear un menú no se mostraba de forma concreta la posición de uso de la nueva función
- Al crear un menú se añadía un mensaje de ayuda, pero no se encontraba la posición de uso
- Los iconos del menú izquierdo del sistema no se podían seleccionar con claridad

## Nuevas funciones

- Nueva gestión de tipos de icono
- Se añaden los usos de los iconos
- Se añade la función de gestión de la biblioteca de iconos
