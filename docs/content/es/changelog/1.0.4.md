> [!NOTE]
> Esta es una versión 1.x anterior a la reescritura (entonces se llamaba AuthX). Para actualizar desde 1.x, consulta [Actualización y migración desde versiones antiguas](/es/deploy/upgrade/).

## Correcciones

- Corrección: el menú izquierdo no se mostraba completo
- Corrección: al formatear o comprimir datos JSON no se vaciaba el contenido del editor derecho
- El menú se ha modificado para encapsularse con un modo recursivo
- Corrección: el menú de segundo nivel no mostraba iconos

## Nuevas funciones

- Nuevos campos de usuario systemed, locked y email para ampliar funciones futuras
- Nueva compatibilidad con información de cabecera de tabla personalizada
- Compatibilidad con cabeceras dinámicas en la página de gestión de cabeceras
- Compatibilidad con la paginación de cabeceras dinámicas
- Nueva herramienta de conversión de JSON a CSV
