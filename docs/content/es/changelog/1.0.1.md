> [!NOTE]
> Esta es una versión 1.x anterior a la reescritura (entonces se llamaba AuthX). Para actualizar desde 1.x, consulta [Actualización y migración desde versiones antiguas](/es/deploy/upgrade/).

## Correcciones

- Al crear contenido no se mostraba un mensaje de ayuda claro
- En la gestión de menús, la paginación no funcionaba tras seleccionar una categoría
- Al crear un menú, tras elegir el tipo de interfaz, el tipo del menú padre no cambiaba según el tipo elegido
- En la página de creación de menús, el cuadro de selección no encajaba con el tema
- La internacionalización de la página estaba incompleta
- Problema: el menú izquierdo no permitía saltar a un menú individual
- Al añadir una dirección de ruta a la interfaz del sistema no se podía autorizar; aparecía el mensaje `this is not active token`

## Nuevas funciones

- Tipos de registro de auditoría
- Función de asignación de permisos a usuarios
- Registro de auditoría
- Gestión de usuarios
