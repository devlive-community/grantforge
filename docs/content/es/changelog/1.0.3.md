> [!NOTE]
> Esta es una versión 1.x anterior a la reescritura (entonces se llamaba AuthX). Para actualizar desde 1.x, consulta [Actualización y migración desde versiones antiguas](/es/deploy/upgrade/).

## Correcciones

- El mensaje de ayuda del menú no coincidía con el menú
- Los datos paginados superaban el ancho de la página
- Al crear un usuario no había respuesta
- Error de compilación
- La función del panel izquierdo no se podía usar y la página se quedaba en blanco

## Nuevas funciones

- Se añade la función de pequeña herramienta JSON
- Nuevo módulo de estadísticas que recopila los datos de usuarios y de registros del panel
