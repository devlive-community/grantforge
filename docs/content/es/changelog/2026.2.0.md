2026.2.0 amplía los permisos de sistemas externos de 2026.1.0 a Apache Hive, Apache Kafka, Apache HBase, Trino y Apache Hadoop YARN. Cada sistema tiene un plugin de servicio y un agente que aplica sus políticas. La lista completa de cambios está en la [comparación de GitHub](https://github.com/devlive-community/grantforge/compare/v2026.1.0...v2026.2.0).

## Apache Hive

- Plugin de servicio de Hive: búsqueda de bases de datos, tablas, columnas y UDF, con inicio de sesión mediante contraseña o Kerberos; consulte [Apache Hive](/es/plugins/hive/).
- Agente de HiveServer2: autoriza cada sentencia, filtra los resultados de `SHOW`, enmascara columnas y filtra filas; consulte el [agente de Hive](/es/external/hive-agent/).
- Las UDF temporales se conceden en el ámbito global solo a `tempudfadmin`, igual que en Apache Ranger, porque ejecutan código elegido por el usuario.

## Apache Kafka

- Plugin de servicio de Kafka: búsqueda de temas, grupos de consumidores, IDs transaccionales y usuarios, con inicio de sesión mediante PLAIN, SCRAM o Kerberos, en texto plano o TLS; consulte [Apache Kafka](/es/plugins/kafka/).
- Autorizador para brokers y controladores: verifica cada solicitud, muestra las políticas como ACL de solo lectura y agrupa los accesos repetidos en un único evento de auditoría; consulte el [agente de Kafka](/es/external/kafka-agent/).

## Apache HBase

- Plugin de servicio de HBase: búsqueda de espacios de nombres, tablas y familias de columnas, a través de ZooKeeper o servidores de arranque, de forma simple o con Kerberos; consulte [Apache HBase](/es/plugins/hbase/).
- Coprocesador para masters y region servers: verifica operaciones, lecturas y escrituras en cada ámbito, devuelve solo las columnas que el usuario puede leer y oculta lo que no puede usar; consulte el [agente de HBase](/es/external/hbase-agent/).

## Trino

- Plugin de servicio de Trino: búsqueda de catálogos, esquemas, tablas, columnas y propiedades de sesión, con inicio de sesión mediante contraseña, JSON Web Token o Kerberos sobre TLS; consulte [Trino](/es/plugins/trino/).
- Dos controles de acceso del sistema: uno para Trino 470 a 478 y otro para 479 y posteriores. Verifican las consultas, listan solo lo que el usuario puede usar, filtran filas y enmascaran columnas; el segundo también verifica ramas de tablas y la actualización de vistas; consulte el [agente de Trino](/es/external/trino-agent/).

## Apache Hadoop YARN

- Plugin de servicio de YARN: conexión a un ResourceManager o a un par de alta disponibilidad, de forma simple o con Kerberos, y búsqueda de colas y nombres de aplicaciones; consulte [Apache Hadoop YARN](/es/plugins/yarn/).
- Proveedor de autorización en los ResourceManagers: decide por política quién puede enviar, a qué colas y la administración del clúster, con condiciones sobre las direcciones de los clientes; consulte el [agente de YARN](/es/external/yarn-agent/).

## Motor de políticas y agentes

- Las políticas deciden el acceso a cualquier recurso de un nivel y a lo que hay debajo de un recurso; así, al listar una base de datos también cuentan las políticas de tablas del usuario.
- Los agentes que verifican cada solicitud agrupan los accesos permitidos idénticos de una ventana de tiempo en un evento de auditoría con un contador y el momento del último; los rechazos se registran de inmediato.
- Los agentes pueden mostrar sus políticas de acceso en los términos propios del sistema.

## Documentación y publicación

- La documentación de los plugins y agentes de YARN, Hive, Kafka, HBase y Trino está disponible en los once idiomas.
- El README enumera los componentes compatibles y las versiones verificadas por las pruebas de integración.
- CI ejecuta, tras una puerta común de Java, solo los trabajos que necesita cada cambio, y rechaza una etiqueta sin su registro de versión.

## Correcciones

- Los índices de PostgreSQL se preparan después de cargar los datos, de modo que las llamadas a la API medidas se ejecutan sobre tablas analizadas.
- Las pruebas del jar del agente de ZooKeeper se ejecutan después del empaquetado.
