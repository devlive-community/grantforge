## Fehlerbehebungen

- Linkes Menü wurde nicht vollständig angezeigt
- Formatieren/Komprimieren von JSON-Daten leerte den rechten Editor nicht
- Menüs werden mit einem rekursiven Muster gekapselt
- Menüpunkte der zweiten Ebene zeigten keine Symbole

## Neue Funktionen

- Neue Benutzerfelder systemed, locked und email für spätere Funktionserweiterungen
- Unterstützung eigener Tabellenkopf-Informationen
- Dynamische Tabellenköpfe auf der Seite zur Tabellenkopf-Verwaltung
- Seitenumbruch bei dynamischen Tabellenköpfen
- Neues Werkzeug zur Umwandlung von JSON in CSV
