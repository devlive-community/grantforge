## 布局

- **左侧菜单**按分组排列：工作空间、访问控制、数据权限、平台管理。
- **顶栏**有快速跳转（⌘K 或 Ctrl+K，按名称搜索页面）、中英文切换、浅色/深色主题和个人菜单。
- **概览**页显示当前租户的账号、部门、用户组与岗位数量，以及工作空间成员和入门步骤。

## 菜单分组

| 分组 | 菜单 | 说明 |
| --- | --- | --- |
| 工作空间 | 概览、我的申请 | 每个登录用户都能看到 |
| 访问控制 | 用户管理、组织架构、用户组、岗位、导入导出、角色管理、职责分离、权限审批、权限复核、在线会话、身份源、审计日志 | 本租户的身份与授权 |
| 数据权限 | 数据服务、策略、代理、访问审计 | 外部数据系统（HDFS、Hive 等）的权限，见 [数据服务、策略与代理](/guide/data-services/) |
| 平台管理 | 租户管理、资源目录、API 目录、授权服务器、目录体检、插件 | 只在平台租户中可用 |

## 为什么我的菜单和别人不一样

控制台本身就是 GrantForge 管理的一个应用：每个页面和按钮都是资源目录里的资源，你能看到哪些菜单、哪些按钮，完全由你的角色决定。

- 持有**租户管理员**系统角色的人能看到本租户的全部“访问控制”和“数据权限”菜单。
- 持有**平台管理员**系统角色的人还能看到“平台管理”。
- 其他人只看到角色授权过的页面；一个分组里一个页面都没有时，整个分组不显示。

> [!NOTE]
> 隐藏菜单只是方便。服务端对每一次 API 调用都会重新检查权限，即使直接输入地址，没有权限的操作也会被拒绝。

授权变化后不需要重新登录：每个答复都带有当前权限的版本号，版本变化时控制台会自动重新加载菜单。
