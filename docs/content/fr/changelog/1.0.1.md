> [!NOTE]
> Il s’agit d’une version 1.x antérieure à la réécriture (elle s’appelait alors AuthX). Pour une mise à niveau depuis 1.x, consultez [Mise à niveau et migration depuis les anciennes versions](/fr/deploy/upgrade/).

## Corrections

- La création de contenu n’affichait aucun message d’information clair
- La pagination ne fonctionnait plus dans la gestion des menus après la sélection d’une catégorie
- Après avoir sélectionné un type d’API pour un nouveau menu, le type du menu parent n’était pas modifié en fonction de la sélection
- Les listes déroulantes de la page de création de menu n’étaient pas harmonisées avec le thème
- Les pages n’étaient pas entièrement internationalisées
- Le menu de gauche ne permettait pas de naviguer vers un élément de menu unique
- Les adresses de chemin ajoutées aux API système ne pouvaient pas être autorisées, avec le message `this is not active token`

## Nouvelles fonctionnalités

- Types de journal d’audit
- Attribution des autorisations aux utilisateurs
- Journaux d’audit
- Gestion des utilisateurs
