> [!NOTE]
> Il s’agit d’une version 1.x antérieure à la réécriture (elle s’appelait alors AuthX). Pour une mise à niveau depuis 1.x, consultez [Mise à niveau et migration depuis les anciennes versions](/fr/deploy/upgrade/).

## Corrections

- Incohérence entre les infobulles des menus et les menus
- Les données paginées dépassaient la largeur de la page
- La création d’un nouvel utilisateur ne produisait aucune réaction
- Erreurs de compilation
- Les fonctions du tableau de bord de gauche étaient inutilisables, la page restant entièrement blanche

## Nouvelles fonctionnalités

- Ajout d’un petit outil JSON
- Ajout d’un module de statistiques couvrant les données des utilisateurs et des journaux du tableau de bord
