**Управление доступом → Проверки доступа**: периодически проверяйте, кто какими ролями владеет. Проверяющие по одному пункту решают, оставить или отозвать, а отозванные назначения удаляются по завершении раунда.

![Проверки доступа](/screenshots/access-reviews.png)

## Планы проверок

| Настройка | Описание |
| --- | --- |
| Имя, описание | Например, «Ежеквартальная проверка финансовых ролей» |
| Роли | Роли для проверки; каждый раунд перечисляет все их текущие назначения |
| Длительность раунда | 1–90 дней; по завершении срока раунд закрывается автоматически |
| Интервал повтора | Оставьте пустым, чтобы раунды запускались только вручную; иначе следующий раунд стартует автоматически через указанный интервал |
| Непроверенные пункты | Пункты без решения по завершении раунда: **оставить** или **отозвать** |
| Включено | Определяет только то, запускаются ли раунды автоматически по расписанию |

## Раунд проверки

1. Нажмите **Начать сейчас** или дождитесь, когда план автоматически запустит раунд. GrantForge создаёт по одному пункту проверки на каждое назначение (кроме системных ролей системных учётных записей).
2. В ходе раунда проверяющие выбирают **Оставить** или **Отозвать** по одному пункту или пачками; при отзыве можно оставить заметку, а решения можно изменить до завершения раунда.
3. Нельзя проверять роли, которыми вы сами владеете через прямое назначение, группу пользователей, подразделение или должность.
4. Администратор может **Завершить раунд** (применить все решения, а нерешённые пункты обработать согласно настройкам плана) или **Отменить раунд** (изменения не вносятся). Раунды, не завершённые в срок, закрываются автоматически.

Отозванные назначения удаляются по завершении раунда. Каждый шаг записывается в журнал аудита, что обеспечивает аудиторский след для проверок внутреннего контроля.
