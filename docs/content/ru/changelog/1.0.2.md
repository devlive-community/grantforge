> [!NOTE]
> Это версия 1.x до переработки (тогда называлась AuthX). Обновление с 1.x см. в [Обновление и миграция со старых версий](/ru/deploy/upgrade/).

## Исправления

- Функции меню нельзя было назначить
- Вверху появлялась пустая страница
- Некоторые записи в управлении журналами не показывали свои детали
- В методах запросов меню присутствовали дублирующиеся данные
- Иконка, заданная для нового меню, не отображалась в иконке меню на странице
- Место использования новой функции меню не отображалось подробно
- Для новых меню были добавлены подсказки, но место их использования нельзя было найти
- Иконки левого меню в системе нельзя было явно выбрать

## Новые возможности

- Добавлено управление типами иконок
- Добавлены варианты использования иконок
- Добавлено управление библиотекой иконок
