> [!NOTE]
> Это версия 1.x до переработки (тогда называлась AuthX). Обновление с 1.x см. в [Обновление и миграция со старых версий](/ru/deploy/upgrade/).

## Исправления

- Подсказки меню не соответствовали меню
- Данные с постраничной навигацией выходили за ширину страницы
- Не было ответа при создании пользователя
- Ошибки компиляции
- Левая панель мониторинга была непригодна для использования, а страница — пустой

## Новые возможности

- Добавлены мини-инструменты JSON
- Добавлен модуль статистики, отчитывающийся о данных пользователей и журналов на панели мониторинга
