## Исправления

- При создании содержимого не выводилось понятное сообщение-подсказка
- В управлении меню переставала работать постраничная навигация после выбора категории
- После выбора типа API для нового меню родительский тип меню не менялся в соответствии с выбором
- Элементы выбора на странице нового меню конфликтовали с темой
- Страницы были не полностью интернационализированы
- Левое меню не могло перейти к отдельному пункту меню
- Пути, добавленные в системные API, нельзя было авторизовать — выводилось `this is not active token`

## Новые возможности

- Типы журналов аудита
- Назначение прав пользователям
- Журналы аудита
- Управление пользователями
