2026.1.0 распространяет права для внешних систем из 2026.0.0 на HDFS, ZooKeeper и MySQL с агентами, которые их применяют, и переводит консоль и документацию на одиннадцать языков. Полный список изменений — в [сравнении на GitHub](https://github.com/devlive-community/grantforge/compare/v2026.0.0...v2026.1.0).

## Apache Hadoop HDFS

- Агенты NameNode по версиям для Hadoop 2.7, 2.10, 3.2, 3.3, 3.4 и 3.5 на общем нативном модуле; см. [агент HDFS NameNode](/ru/external/hdfs-agent/).
- Kerberos на всех линиях Hadoop, кластеры из нескольких областей и вход, сохраняемый между запросами; доверие к `swebhdfs` настраивается для каждого сервиса.
- Проверено на кластерах с Kerberos и при автоматическом переключении HA, от Hadoop 2.10 до 3.5.
- Агент сообщает о решениях через метрики Hadoop и закрепляет применяемый снимок политик.

## Apache ZooKeeper

- Плагин сервиса ZooKeeper с сеансами TLS и постраничным поиском znode.
- Серверный агент, который решает маркерный ACL по политикам сервиса; см. [агент ZooKeeper](/ru/external/zookeeper-agent/).

## MySQL

- Плагин сервиса MySQL: поиск баз данных, таблиц и столбцов, политики доступа, маскирования и фильтрации строк; см. [MySQL](/ru/plugins/mysql/).
- Прокси-агент MySQL, который проверяет операторы вплоть до столбцов, маскирует значения и фильтрует строки; см. [прокси-агент MySQL](/ru/external/mysql-agent/).

## Плагины и политики

- Агенты применяют политики маскирования и фильтрации строк.
- Редакторы политик просматривают каталоги сервиса для выбора путей.
- Неудачный поиск сообщает причину: сервис недоступен, вход отклонён или не хватает прав.
- Перед отключением плагина показывается, на что это повлияет.
- У продуктовых плагинов есть собственный раздел документации.

## Консоль

- Одиннадцать языков интерфейса: упрощённый и традиционный китайский, английский, японский, корейский, русский, немецкий, французский, испанский, бразильский португальский и итальянский; язык выбирается из списка и на странице первоначальной настройки.
- Двухэтапный вход настраивается сканированием QR-кода; форма входа показывает каталоги, через которые можно войти.
- Страница учётной записи разделена на вкладки с собственными адресами; журналы аудита и каталог API используют общий для всех списков переключатель страниц.
- Действия в строках — кнопки-значки с подсказками; диалоги анимируются в обе стороны и игнорируют щелчки по фону; для дат используется календарь; по дереву ресурсов можно искать.
- Проверка форм отмечает каждое ошибочное поле подсказкой рядом с ним.

## Документация

- Сайт документации публикуется на тех же одиннадцати языках, с поиском слов на хангыле и кириллице.

## Исправления

- MySQL: привязка SLF4J агента больше не попадает в журнал сервера; сопоставления идентичностей объявлены как отображения.
- ZooKeeper: обновление Netty, устраняющее его уведомления безопасности, и укреплённые сеансы TLS.
- Неудачные запросы к сервису сообщаются как ошибки клиента; встроенные плагины сообщают версию продукта.
- Множество исправлений консоли в диалогах, подсказках проверки, прокрутке и формах сервисов данных.
