> [!NOTE]
> Это версия 1.x до переработки (тогда называлась AuthX). Обновление с 1.x см. в [Обновление и миграция со старых версий](/ru/deploy/upgrade/).

## Исправления

- Исправлено неполное отображение левого меню
- Исправлено неочищение правого редактора при форматировании/минификации данных JSON
- Меню теперь инкапсулируются с помощью рекурсивного подхода
- Исправлено отсутствие иконок у пунктов меню второго уровня

## Новые возможности

- Добавлены поля пользователей systemed, locked и email для будущего расширения функций
- Добавлена поддержка пользовательской информации в заголовках таблиц
- Добавлены динамические заголовки на странице управления заголовками таблиц
- Добавлена постраничная навигация для динамических заголовков
- Добавлен инструмент преобразования JSON в CSV
