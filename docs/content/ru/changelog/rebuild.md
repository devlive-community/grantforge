2026.0.0 — полная переработка, заменяющая 1.x (AuthX). Это уже не шаблон администратора, а самостоятельная платформа идентификации и разрешений. Учётные записи, роли и меню из 1.x можно импортировать; см. [Обновление и миграция со старых версий](/ru/deploy/upgrade/).

## Платформа

- Spring Boot 4 и среда выполнения Java 17; единый пакет релиза содержит сервер и консоль, также предоставляются Docker-образы, Compose и Helm Chart.
- Поддерживаются H2, PostgreSQL, MySQL, MariaDB, Oracle и SQL Server; миграциями управляет Liquibase, и каждый коммит тестируется на девяти версиях баз данных.
- Мастер инициализации при первом запуске, создающий администратора платформы с помощью одноразового токена из журналов сервиса.
- Кластерное развёртывание: сессии хранятся в базе данных, а идентификаторы являются упорядоченными по времени TSID.
- Совершенно новая консоль: Vue 3 и Tailwind CSS, светлая и тёмная темы, китайский и английский языки.

## Идентификация и организация

- Мультиарендность: учётные записи, организации и авторизации полностью изолированы для каждого арендатора.
- Пользователи, деревья подразделений, группы пользователей и должности с массовым импортом и экспортом в CSV.
- Пароли Argon2id, настраиваемые политики паролей и блокировки, управление сессиями, двухшаговая проверка TOTP с резервными кодами и повторная проверка для чувствительных операций.
- Источники идентификации LDAP / Active Directory и OIDC с синхронизацией и федеративным входом.

## Авторизация

- Каталог ресурсов: модули, меню, страницы, вкладки, кнопки, API, сущности данных и поля, а также зависимости между ними. Собственные страницы, кнопки и API консоли тоже входят в каталог и подчиняются той же авторизации.
- Роли и авторизация: разрешение и запрещение, наследование, назначение по пользователю / группе пользователей / подразделению / должности и периоды действия.
- Права на данные: ограничение видимых строк областью организации или структурированными условиями.
- Права на поля: скрытие, маскирование или ограничение полей только чтением в зависимости от роли.
- Объяснение прав, симуляция для каждого пользователя, полные журналы аудита и проверки некорректных конфигураций.

## Управление

- Разделение обязанностей: взаимоисключающие роли отклоняются при назначении, наследовании и запросах, а существующие конфликты можно обнаружить.
- Запросы прав: пользователи запрашивают доступные роли; после одобрения они действуют ограниченное время и автоматически отзываются по истечении срока.
- Периодический пересмотр прав.

## Интеграция приложений

- Встроенный сервер авторизации OAuth 2.1 / OpenID Connect: код авторизации + PKCE, учётные данные клиента, ротация refresh-токенов и ротация ключей подписи.
- Open API для запросов прав с версионированием и ETags.
- Spring Boot Starter и JavaScript SDK с рабочими примерами приложений.

## Права на внешние системы

- Расширяемые типы сервисов: плагины определяют иерархии ресурсов, типы доступа, маскирование и фильтрацию строк; каждый плагин загружается независимо.
- Универсальный редактор политик, подписанные Ed25519 снимки политик, heartbeat'ы агентов и аудит доступа.
- Демонстрационные плагины, тип сервиса HDFS и агент NameNode для Hadoop 3.5.0; плагин Hive и агенты для других версий Hadoop находятся в разработке.

## Качество

- Бенчмарки производительности в масштабе миллиона учётных записей запускаются ежедневно и завершаются ошибкой при превышении пределов.
- Статический анализ (NullAway, Error Prone, Checkstyle, PMD, SpotBugs, ArchUnit), пороги покрытия и сквозные браузерные тесты.
- Сайт документации пересобран на Next.js и Tailwind CSS.
