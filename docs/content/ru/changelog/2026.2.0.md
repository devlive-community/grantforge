2026.2.0 распространяет права внешних систем из 2026.1.0 на Apache Hive, Apache Kafka, Apache HBase, Trino и Apache Hadoop YARN, с агентами, которые их применяют. Полный список изменений — в [сравнении на GitHub](https://github.com/devlive-community/grantforge/compare/v2026.1.0...v2026.2.0).

## Apache Hive

- Сервисный плагин Hive: базы данных, таблицы, столбцы, UDF, URL, служба HiveServer2 и репликация, с типами доступа Hive, как их определяет Apache Ranger; см. [Apache Hive](/ru/plugins/hive/).
- Агент HiveServer2, который проверяет каждый оператор, фильтрует результаты `SHOW`, маскирует столбцы и фильтрует строки; см. [агент Hive](/ru/external/hive-agent/).
- Временные UDF на глобальном уровне выдаются только `tempudfadmin`, как в Apache Ranger, поскольку они выполняют код, выбранный пользователем.

## Apache Kafka

- Сервисный плагин Kafka: топики, группы, транзакционные ID, кластер, делегирующие токены и пользователи SCRAM, с типами доступа и импликациями, присущими Kafka; см. [Apache Kafka](/ru/plugins/kafka/).
- Авторизатор брокеров и контроллеров, который проверяет каждый запрос; см. [агент Kafka](/ru/external/kafka-agent/).

## Apache HBase

- Сервисный плагин HBase: пространства имён, таблицы, семейства столбцов и столбцы, а также глобальный уровень для операций со всем кластером; см. [Apache HBase](/ru/plugins/hbase/).
- Координатор для мастера и region-серверов, который проверяет операции, возвращает только те столбцы, которые пользователь может читать, и скрывает то, что ему не видно; см. [агент HBase](/ru/external/hbase-agent/).

## Trino

- Сервисный плагин Trino: каталоги, схемы, таблицы, столбцы, функции, процедуры и свойства сеанса; см. [Trino](/ru/plugins/trino/).
- Два системных контроля доступа: один для Trino 470–478 и один для Trino 479 и новее, которые проверяют запросы, фильтруют строки и маскируют столбцы; см. [агенты Trino](/ru/external/trino-agent/).

## Apache Hadoop YARN

- Сервисный плагин YARN: очереди и приложения, с типами доступа YARN `submit_app` и `admin_queue`; см. [Apache Hadoop YARN](/ru/plugins/yarn/).
- Провайдер авторизации в ResourceManager, который решает отправку, очереди и администрирование кластера по политике, с условиями по адресам клиентов; см. [агент YARN](/ru/external/yarn-agent/).

## Движок политик и агенты

- Политики решают доступ к тому, что находится ниже ресурса: просмотр базы данных учитывает политики таблиц пользователя, а новый тип доступа `_any` разрешается, когда разрешён доступ к ресурсу или к чему-то ниже него.
- Политики отвечают, может ли пользователь что-либо сделать с каким-то ресурсом уровня, как Kafka спрашивает перед записью идемпотентных продюсеров.
- Агенты объединяют одинаковые разрешённые обращения за временное окно в одно событие аудита с количеством и моментом последнего; отказы записываются сразу.
- Агенты могут показывать свои политики доступа в терминах самой системы.
- API плагинов 1.2.0 предоставляет области Kerberos всем плагинам один раз, и они больше не перезаписывают друг другу `krb5.conf`.

## Документация и выпуск

- Плагины и агенты YARN, Hive, Kafka, HBase и Trino документированы на всех одиннадцати языках.
- README перечисляет поддерживаемые компоненты и версии, которые проверяют интеграционные тесты.
- Теги выпусков запускают полный CI, и выпуск ожидает этот запуск; дистрибутив собирается параллельно; npm публикует через доверенную публикацию (trusted publishing).
- Версии без журнала выпуска отклоняются при создании тега; после общего Java-шлюза CI запускает только задачи, которые нужны изменению.

## Исправления

- Индексы PostgreSQL готовятся после наполнения данными, чтобы замеряемые вызовы API выполнялись на проанализированных таблицах.
- Тесты jar-файлов агента ZooKeeper запускаются после упаковки.
- Развёртывания Maven пропускают интеграционные тесты; тайм-аут forked JVM на агенте HDFS 3.2 приводил к сбою развёртывания в GitHub Packages.
- Пакет npm объявляет свой репозиторий, чтобы npm мог проверить provenance.
