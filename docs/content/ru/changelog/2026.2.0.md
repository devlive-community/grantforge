2026.2.0 расширяет права внешних систем из 2026.1.0 на Apache Hive, Apache Kafka, Apache HBase, Trino и Apache Hadoop YARN. У каждой системы есть сервисный плагин и агент, который применяет её политики. Полный список изменений — в [сравнении на GitHub](https://github.com/devlive-community/grantforge/compare/v2026.1.0...v2026.2.0).

## Apache Hive

- Сервисный плагин Hive: поиск баз данных, таблиц, столбцов и UDF, вход по паролю или Kerberos; см. [Apache Hive](/ru/plugins/hive/).
- Агент HiveServer2: авторизует каждый оператор, фильтрует результаты `SHOW`, маскирует столбцы и фильтрует строки; см. [агент Hive](/ru/external/hive-agent/).
- Временные UDF на глобальном уровне выдаются только `tempudfadmin`, как и в Apache Ranger, так как они выполняют код, выбранный пользователем.

## Apache Kafka

- Сервисный плагин Kafka: поиск топиков, групп потребителей, транзакционных ID и пользователей, вход по PLAIN, SCRAM или Kerberos, открытым текстом или по TLS; см. [Apache Kafka](/ru/plugins/kafka/).
- Авторизатор брокеров и контроллеров: проверяет каждый запрос, показывает политики как ACL только для чтения и объединяет повторные обращения в одно событие аудита; см. [агент Kafka](/ru/external/kafka-agent/).

## Apache HBase

- Сервисный плагин HBase: поиск пространств имён, таблиц и семейств столбцов через ZooKeeper или серверы начальной загрузки, простым входом или с Kerberos; см. [Apache HBase](/ru/plugins/hbase/).
- Координатор для мастеров и region server: проверяет операции, чтение и запись на каждом уровне, возвращает только столбцы, доступные пользователю для чтения, и скрывает то, чем он не может пользоваться; см. [агент HBase](/ru/external/hbase-agent/).

## Trino

- Сервисный плагин Trino: поиск каталогов, схем, таблиц, столбцов и свойств сеанса, вход по паролю, JSON Web Token или Kerberos поверх TLS; см. [Trino](/ru/plugins/trino/).
- Два системных контроля доступа: один для Trino 470–478, другой для 479 и новее. Они проверяют запросы, перечисляют только доступное пользователю, фильтруют строки и маскируют столбцы; второй дополнительно проверяет ветки таблиц и обновление представлений; см. [агент Trino](/ru/external/trino-agent/).

## Apache Hadoop YARN

- Сервисный плагин YARN: подключение к одному ResourceManager или высокодоступной паре, простым входом или с Kerberos, поиск очередей и имён приложений; см. [Apache Hadoop YARN](/ru/plugins/yarn/).
- Провайдер авторизации в ResourceManager: по политике решает, кто может отправлять приложения, в какие очереди и кто администрирует кластер, с условиями по адресам клиентов; см. [агент YARN](/ru/external/yarn-agent/).

## Движок политик и агенты

- Политики решают доступ к любому ресурсу уровня и к тому, что находится ниже ресурса; поэтому при просмотре базы данных учитываются политики таблиц пользователя.
- Агенты, проверяющие каждый запрос, объединяют одинаковые разрешённые обращения за временное окно в одно событие аудита со счётчиком и временем последнего обращения; отказы фиксируются сразу.
- Агенты могут показывать свои политики доступа в терминах самой системы.

## Документация и выпуск

- Документация плагинов и агентов YARN, Hive, Kafka, HBase и Trino доступна на одиннадцати языках.
- README перечисляет поддерживаемые компоненты и версии, проверенные интеграционными тестами.
- CI после общего Java-шлюза запускает только задания, нужные конкретному изменению, и отклоняет тег без журнала выпуска.

## Исправления

- Индексы PostgreSQL подготавливаются после заполнения данных, поэтому замеряемые вызовы API выполняются на проанализированных таблицах.
- Тесты jar-файла агента ZooKeeper запускаются после сборки пакета.
