**플랫폼 관리 → 테넌트 관리**: 각 테넌트는 서로 격리된 조직으로, 자체 사용자와 권한을 가집니다. 플랫폼 테넌트는 플랫폼 관리자를 두는 테넌트이며 비활성화할 수 없습니다.

![테넌트 관리](/screenshots/tenants.png)

## 테넌트 생성

테넌트 코드와 이름, 그리고 이 테넌트의 첫 관리자에 대한 사용자 이름, 표시 이름, 비밀번호를 입력합니다. 첫 관리자는 이 테넌트의 "테넌트 관리자" 시스템 역할을 가지며, 최초 로그인 시 비밀번호를 변경해야 합니다. 사용자 이름은 전체 플랫폼에서 유일합니다.

## 비활성화와 활성화

테넌트를 비활성화하면 해당 테넌트의 모든 계정이 즉시 로그아웃되고 로그인할 수 없으며, 이미 발급된 애플리케이션 토큰도 더 이상 갱신되지 않습니다. 데이터는 삭제되지 않으며, 다시 활성화하면 복원됩니다.

## 플랫폼 테넌트

플랫폼 테넌트는 초기화 시 생성되는 첫 테넌트입니다. 이 테넌트의 관리자는 전체 테넌트, [리소스 카탈로그와 API 카탈로그](/ko/guide/catalog/), 인가 서버, 플러그인을 관리할 수 있습니다. 비즈니스 애플리케이션과 그 리소스는 전체 플랫폼이 공유되며, 각 테넌트는 자신의 역할에서 이 리소스에 권한을 부여합니다.
