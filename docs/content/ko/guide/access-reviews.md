**접근 제어 → 권한 검토**는 누가 어떤 역할을 가지고 있는지 정기적으로 검토합니다. 검토자가 항목별로 유지 또는 회수를 결정하고, 회수된 할당은 해당 회차가 끝날 때 제거됩니다.

![권한 검토](/screenshots/access-reviews.png)

## 검토 계획

| 설정 | 설명 |
| --- | --- |
| 이름, 설명 | 예를 들어 "재무 역할 분기 검토" |
| 역할 | 검토할 역할입니다. 각 회차는 이 역할들의 현재 할당을 모두 나열합니다 |
| 회차 기간 | 1–90일이며, 기간이 끝나면 해당 회차가 자동으로 완료됩니다 |
| 반복 간격 | 비워 두면 수동으로만 시작하며, 값을 넣으면 해당 간격마다 다음 회차가 자동으로 시작됩니다 |
| 검토하지 않은 항목 | 회차가 끝날 때 결정하지 않은 항목의 처리 방법입니다. **유지** 또는 **회수** |
| 활성화 | 계획에 따라 자동으로 시작할지 여부에만 영향을 줍니다 |

## 검토 한 회차

1. **즉시 시작**을 클릭하거나 계획이 자동으로 시작할 때까지 기다립니다. GrantForge는 할당마다 검토 항목을 하나씩 만듭니다(시스템 계정의 시스템 역할은 제외).
2. 검토자는 이 회차 동안 항목별로 또는 일괄적으로 **유지** 또는 **회수**를 선택합니다. 회수에는 설명을 입력할 수 있고, 결정은 이번 회차가 끝나기 전에 철회할 수 있습니다.
3. 직접 할당, 사용자 그룹, 부서 또는 직위를 통해 얻게 된 자신의 역할은 검토할 수 없습니다.
4. 관리자는 **회차 완료**(모든 결정을 적용하고, 결정하지 않은 항목은 계획 설정에 따라 처리) 또는 **회차 취소**(아무 변경도 하지 않음)를 할 수 있습니다. 기한 내에 끝내지 못한 회차는 자동으로 완료됩니다.

회수된 할당은 이번 회차가 완료될 때 삭제됩니다. 모든 단계가 감사 로그에 기록되므로, 내부 통제 감사의 흔적으로 활용하기에 적합합니다.
