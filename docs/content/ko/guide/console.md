## 구성

- **왼쪽 메뉴**는 그룹별로 정렬됩니다. 작업 공간, 접근 제어, 데이터 권한, 플랫폼 관리.
- **상단 바**에는 빠른 이동(⌘K 또는 Ctrl+K, 이름으로 페이지 검색), 언어 전환, 라이트/다크 테마, 개인 메뉴가 있습니다.
- **개요** 페이지에는 현재 테넌트의 계정, 부서, 사용자 그룹, 직위 수와 작업 공간 멤버, 시작 단계가 표시됩니다.

## 메뉴 그룹

| 그룹 | 메뉴 | 설명 |
| --- | --- | --- |
| 작업 공간 | 개요, 내 요청 | 로그인한 사용자라면 누구나 볼 수 있음 |
| 접근 제어 | 사용자 관리, 조직 구조, 사용자 그룹, 직위, 가져오기와 내보내기, 역할 관리, 직무 분리, 권한 승인, 권한 검토, 온라인 세션, 신원 소스, 감사 로그 | 이 테넌트의 신원과 권한 부여 |
| 데이터 권한 | 데이터 서비스, 정책, 에이전트, 접근 감사 | 외부 데이터 시스템(HDFS, Hive 등)에 대한 권한. [데이터 서비스, 정책과 에이전트](/ko/external/data-services/) 참고 |
| 플랫폼 관리 | 테넌트 관리, 리소스 카탈로그, API 카탈로그, 권한 부여 서버, 카탈로그 검사, 플러그인 | 플랫폼 테넌트에서만 사용 가능 |

## 내 메뉴가 다른 사람과 다른 이유

콘솔 자체가 GrantForge가 관리하는 애플리케이션입니다. 모든 페이지와 버튼이 리소스 카탈로그의 리소스이므로, 어떤 메뉴와 버튼이 보이는지는 전적으로 사용자의 역할이 결정합니다.

- **테넌트 관리자** 시스템 역할을 가진 사람은 이 테넌트의 "접근 제어"와 "데이터 권한" 메뉴를 모두 볼 수 있습니다.
- **플랫폼 관리자** 시스템 역할을 가진 사람은 "플랫폼 관리"도 볼 수 있습니다.
- 그 밖의 사람은 역할에 권한이 부여된 페이지만 봅니다. 한 그룹에 표시할 페이지가 하나도 없으면 그룹 전체가 나타나지 않습니다.

> [!NOTE]
> 메뉴를 숨기는 것은 편의를 위한 것일 뿐입니다. 서버는 모든 API 호출에서 권한을 다시 검사하므로, 주소를 직접 입력하더라도 권한이 없는 작업은 거부됩니다.

권한 부여가 바뀌어도 다시 로그인할 필요가 없습니다. 모든 응답에 현재 권한의 버전 번호가 포함되어 있고, 버전이 바뀌면 콘솔이 메뉴를 자동으로 다시 불러옵니다.
