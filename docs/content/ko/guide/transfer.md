**접근 제어 → 가져오기와 내보내기**는 CSV 파일로 사용자와 조직 구조를 대량으로 가져오거나 내보냅니다.

![가져오기와 내보내기](/screenshots/transfer.png)

## 가져오기

1. **템플릿 다운로드**를 클릭하고 "열 설명"을 참고해 입력합니다. 헤더는 대소문자를 구분하지 않고, 불필요한 열은 무시합니다. 사용자의 부서와 직위는 코드로 입력하며, 여러 개는 세미콜론으로 구분합니다.
2. 파일을 업로드하고 **사전 검사**를 클릭합니다. GrantForge가 한 줄씩 검사하며 문제가 있는 곳마다 보고합니다(줄 번호, 열, 원인).
3. 모두 통과하면 **N줄 가져오기 확인**을 클릭합니다. 한 줄이라도 문제가 있으면 아무것도 저장하지 않으므로, 가져오기가 절반만 끝나는 일은 없습니다.

규칙:

- 파일 인코딩은 UTF-8 또는 GBK일 수 있습니다(Excel로 중국어 CSV를 저장할 때의 기본값은 GBK). 인코딩은 자동으로 판별합니다.
- 파일 하나에 사용자는 최대 1,000명, 부서는 최대 5,000개까지 담을 수 있고, 크기는 2 MB를 넘을 수 없습니다(설정 가능).
- 부서 가져오기는 상위 관계에 따라 자동으로 정렬되므로, 파일 안에서 상위 부서가 하위 부서보다 뒤에 있어도 됩니다. 파일 안에서 순환이 생기면 보고합니다.
- 사용자의 초기 비밀번호는 비밀번호 정책을 만족해야 하며, 가져온 사용자는 처음 로그인할 때 비밀번호를 변경해야 합니다.
- 데이터 권한으로 볼 수 있는 부서와 직위로만 가져올 수 있습니다.

## 내보내기

현재 조건에 맞는 사용자 또는 전체 부서를 내보냅니다. 파일 이름에는 날짜가 들어가며, 예를 들어 `users-2026-10-05.csv`입니다. 내보내기도 데이터 권한과 필드 권한을 지킵니다. 보이지 않는 행은 내보내지 않고, 제한된 필드는 해당 규칙에 따라 숨기거나 마스킹합니다. `=`, `+`, `-`, `@`로 시작하는 셀에는 접두사를 붙여, 스프레드시트 프로그램이 이를 수식으로 실행하지 않도록 합니다.
