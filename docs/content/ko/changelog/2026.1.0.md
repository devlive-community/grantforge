2026.1.0은 2026.0.0의 외부 시스템 권한을 HDFS, ZooKeeper, MySQL로 넓히고 이를 적용하는 에이전트를 제공하며, 콘솔과 문서를 11개 언어로 제공합니다. 전체 변경 사항은 [GitHub 비교](https://github.com/devlive-community/grantforge/compare/v2026.0.0...v2026.1.0)에서 볼 수 있습니다.

## Apache Hadoop HDFS

- Hadoop 2.7, 2.10, 3.2, 3.3, 3.4, 3.5용 버전별 NameNode 에이전트와 공통 네이티브 모듈. [HDFS NameNode 에이전트](/ko/external/hdfs-agent/)를 참고하세요.
- 모든 Hadoop 버전 라인의 Kerberos, 여러 영역에 걸친 클러스터, 조회 사이에 유지되는 로그인. `swebhdfs`는 서비스별로 신뢰합니다.
- Hadoop 2.10부터 3.5까지 Kerberos 클러스터와 자동 HA 장애 조치에서 검증했습니다.
- 에이전트는 Hadoop 메트릭으로 결정을 보고하고 적용하는 정책 스냅숏을 고정합니다.

## Apache ZooKeeper

- TLS 세션과 페이지 단위 znode 조회를 지원하는 ZooKeeper 서비스 플러그인.
- 서비스 정책으로 마커 ACL을 결정하는 서버 측 에이전트. [ZooKeeper 에이전트](/ko/external/zookeeper-agent/)를 참고하세요.

## MySQL

- 데이터베이스·테이블·컬럼 조회와 접근·마스킹·행 필터 정책을 제공하는 MySQL 서비스 플러그인. [MySQL](/ko/plugins/mysql/)을 참고하세요.
- 문을 컬럼 단위까지 검사하고 값을 마스킹하며 행을 필터링하는 MySQL 프록시 에이전트. [MySQL 프록시 에이전트](/ko/external/mysql-agent/)를 참고하세요.

## 플러그인과 정책

- 에이전트가 마스킹과 행 필터 정책을 평가합니다.
- 정책 편집기에서 서비스 디렉터리를 탐색해 경로를 고를 수 있습니다.
- 조회가 실패하면 연결 불가, 로그인 거부, 권한 부족 등 이유를 알려 줍니다.
- 플러그인을 비활성화하기 전에 영향을 받는 대상을 먼저 보여 줍니다.
- 제품 플러그인은 문서에 별도 섹션이 있습니다.

## 콘솔

- 11개 인터페이스 언어: 중국어 간체·번체, 영어, 일본어, 한국어, 러시아어, 독일어, 프랑스어, 스페인어, 브라질 포르투갈어, 이탈리아어. 목록이나 초기 설정 페이지에서 고릅니다.
- QR 코드를 스캔해 2단계 로그인을 설정하고, 로그인 양식에 로그인할 수 있는 디렉터리가 표시됩니다.
- 계정 페이지는 자체 주소를 가진 탭으로 나뉘고, 감사 로그와 API 카탈로그는 모든 목록과 같은 페이지 이동기를 씁니다.
- 행 작업은 도움말이 있는 아이콘 버튼이 되었고, 대화 상자는 양방향 애니메이션과 함께 배경 클릭을 무시하며, 날짜는 달력 선택기를 쓰고, 리소스 트리를 검색할 수 있습니다.
- 양식 검증은 오류가 난 모든 필드를 옆의 도움말로 표시합니다.

## 문서

- 문서 사이트도 같은 11개 언어로 제공되며, 한글과 키릴 문자 검색을 지원합니다.

## 버그 수정

- MySQL: 에이전트의 SLF4J 바인딩이 서버 로거에 섞이지 않으며, 아이디 매핑을 맵으로 선언합니다.
- ZooKeeper: 보안 권고를 해소하는 Netty 업데이트와 강화된 TLS 세션.
- 실패한 서비스 조회를 클라이언트 오류로 보고하고, 내장 플러그인이 제품 버전을 보고합니다.
- 대화 상자, 검증 도움말, 스크롤, 데이터 서비스 양식에 대한 여러 콘솔 수정.
