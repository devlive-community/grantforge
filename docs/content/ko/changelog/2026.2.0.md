2026.2.0은 2026.1.0의 외부 시스템 권한을 Apache Hive, Apache Kafka, Apache HBase, Trino, Apache Hadoop YARN으로 확장합니다. 각 시스템에는 서비스 플러그인과 정책을 적용하는 에이전트가 있습니다. 전체 변경 사항은 [GitHub 비교](https://github.com/devlive-community/grantforge/compare/v2026.1.0...v2026.2.0)에서 볼 수 있습니다.

## Apache Hive

- Hive 서비스 플러그인: 데이터베이스, 테이블, 열, UDF 조회. 비밀번호 또는 Kerberos로 로그인합니다. [Apache Hive](/ko/plugins/hive/)를 참고하세요.
- HiveServer2 에이전트: 모든 문장을 인가하고, `SHOW` 결과를 걸러내며, 열을 마스킹하고 행을 필터링합니다. [Hive 에이전트](/ko/external/hive-agent/)를 참고하세요.
- 임시 UDF는 전역 범위에서 `tempudfadmin`에게만 부여됩니다. 사용자가 고른 코드를 실행하므로 Apache Ranger와 같은 방식입니다.

## Apache Kafka

- Kafka 서비스 플러그인: 토픽, 컨슈머 그룹, 트랜잭션 ID, 사용자 조회. PLAIN, SCRAM 또는 Kerberos로, 평문 또는 TLS를 사용합니다. [Apache Kafka](/ko/plugins/kafka/)를 참고하세요.
- 브로커 및 컨트롤러 인가 에이전트: 모든 요청을 확인하고, 정책을 읽기 전용 ACL로 보여 주며, 반복되는 접근을 하나의 감사 이벤트로 묶습니다. [Kafka 에이전트](/ko/external/kafka-agent/)를 참고하세요.

## Apache HBase

- HBase 서비스 플러그인: 네임스페이스, 테이블, 컬럼 패밀리 조회. ZooKeeper 또는 부트스트랩 서버를 통해, 단순 또는 Kerberos로 연결합니다. [Apache HBase](/ko/plugins/hbase/)를 참고하세요.
- 마스터 및 리전 서버 코프로세서: 모든 범위에서 작업, 읽기, 쓰기를 확인하고, 사용자가 읽을 수 있는 열만 반환하며, 사용할 수 없는 항목은 숨깁니다. [HBase 에이전트](/ko/external/hbase-agent/)를 참고하세요.

## Trino

- Trino 서비스 플러그인: 카탈로그, 스키마, 테이블, 열, 세션 속성 조회. 비밀번호, JSON 웹 토큰 또는 TLS 위의 Kerberos로 로그인합니다. [Trino](/ko/plugins/trino/)를 참고하세요.
- 두 개의 시스템 액세스 제어: Trino 470~478용과 479 이후용입니다. 쿼리를 확인하고, 사용자가 쓸 수 있는 항목만 나열하며, 행을 필터링하고 열을 마스킹합니다. 후자는 테이블 브랜치와 뷰 새로 고침도 확인합니다. [Trino 에이전트](/ko/external/trino-agent/)를 참고하세요.

## Apache Hadoop YARN

- YARN 서비스 플러그인: 하나의 ResourceManager 또는 고가용성 쌍에 연결하고, 단순 또는 Kerberos로 로그인하며, 큐와 애플리케이션 이름을 조회합니다. [Apache Hadoop YARN](/ko/plugins/yarn/)을 참고하세요.
- ResourceManager의 인가 제공자: 제출, 큐, 클러스터 관리 권한을 정책으로 결정하며, 클라이언트 주소 조건을 지원합니다. [YARN 에이전트](/ko/external/yarn-agent/)를 참고하세요.

## 정책 엔진과 에이전트

- 정책은 계층의 임의 리소스에 대한 접근과, 리소스 하위 항목에 대한 접근을 결정할 수 있습니다. 그래서 데이터베이스를 나열하면 사용자의 테이블 정책도 계산에 포함됩니다.
- 모든 요청을 확인하는 에이전트는 일정 시간 창 안의 동일한 허용 접근을 횟수와 마지막 시각이 담긴 하나의 감사 이벤트로 묶습니다. 거부된 접근은 즉시 기록됩니다.
- 에이전트는 해당 시스템 고유의 용어로 접근 정책을 보여 줄 수 있습니다.

## 문서와 릴리스

- YARN, Hive, Kafka, HBase, Trino 플러그인과 에이전트 문서는 11개 언어로 제공됩니다.
- README에는 지원되는 구성 요소와 통합 테스트로 검증된 버전이 나열되어 있습니다.
- CI는 한 번의 Java 게이트를 통과한 뒤 변경에 필요한 작업만 실행하며, 릴리스 로그가 없는 태그는 거부합니다.

## 수정 사항

- 시드 데이터를 넣은 뒤 PostgreSQL 인덱스를 준비하여, 시간을 재는 API 호출이 분석된 테이블에서 실행되도록 했습니다.
- ZooKeeper 에이전트의 jar 테스트를 패키징 후에 실행합니다.
