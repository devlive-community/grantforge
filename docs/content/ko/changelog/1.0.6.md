> [!NOTE]
> 이것은 재구축 이전 1.x 버전입니다(당시 이름은 AuthX). 1.x에서 업그레이드하려면 [업그레이드와 이전 버전 마이그레이션](/ko/deploy/upgrade/)을 참고하세요.

## Core

- 소스 디렉터리 구조를 새로 구축
- 핵심 부분의 소스 코드를 리팩터링
- 일부 `Controller`, `Service`를 최적화

## Web

- UI 컴포넌트를 `view-ui-plus`로 교체
- `Vue3` + `TypeScript`로 다시 작성
