> [!NOTE]
> 이것은 재구축 이전 1.x 버전입니다(당시 이름은 AuthX). 1.x에서 업그레이드하려면 [업그레이드와 이전 버전 마이그레이션](/ko/deploy/upgrade/)을 참고하세요.

## 수정

- 메뉴 기능을 배정할 수 없는 문제 수정
- 상단에 빈 페이지가 나타나는 문제 수정
- 로그 관리에서 특정 로그의 상세 내용을 볼 수 없는 문제 수정
- 메뉴의 요청 방식에 중복 데이터가 있는 문제 수정
- 메뉴를 만들 때 아이콘을 설정해도 단일 페이지 메뉴 아이콘이 바뀌지 않는 문제 수정
- 새로 만든 메뉴의 새 기능 사용 위치가 구체적으로 표시되지 않는 문제 수정
- 메뉴를 만들 때 도움말 메시지를 추가했지만 사용 위치를 찾을 수 없는 문제 수정
- 시스템 왼쪽 메뉴 아이콘을 명확하게 선택할 수 없는 문제 수정

## 새 기능

- 아이콘 타입 관리 추가
- 아이콘 용도 추가
- 아이콘 라이브러리 관리 기능 추가
