> [!NOTE]
> 이것은 재구축 이전 1.x 버전입니다(당시 이름은 AuthX). 1.x에서 업그레이드하려면 [업그레이드와 이전 버전 마이그레이션](/ko/deploy/upgrade/)을 참고하세요.

## 수정

- 새로 만들 때 명확한 도움말 메시지가 표시되지 않는 문제 수정
- 메뉴 관리에서 분류를 선택한 뒤 페이징을 사용할 수 없는 문제 수정
- 메뉴를 만들 때 인터페이스 타입을 선택해도 상위 메뉴 타입이 선택한 타입에 따라 바뀌지 않는 문제 수정
- 메뉴 만들기 페이지의 선택 상자가 테마와 어울리지 않는 문제 수정
- 페이지 국제화가 완전하지 않은 문제 수정
- 왼쪽 메뉴에서 단일 메뉴로 이동할 수 없는 문제 수정
- 시스템 인터페이스에 추가한 경로 주소를 권한 부여할 수 없고 `this is not active token` 메시지가 표시되는 문제 수정

## 새 기능

- 감사 로그 타입
- 사용자 권한 배정 기능
- 감사 로그
- 사용자 관리
