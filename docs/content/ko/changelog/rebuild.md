2026.0.0은 1.x(AuthX)를 대체하는 완전한 재구축입니다. 더 이상 백오피스 템플릿이 아니라 독립적으로 배포되는 신원과 권한 플랫폼입니다. 1.x의 계정, 역할, 메뉴는 가져올 수 있습니다. [업그레이드와 이전 버전 마이그레이션](/ko/deploy/upgrade/)을 참고하세요.

## 플랫폼

- Spring Boot 4, Java 17 런타임. 하나의 릴리스 패키지에 서버와 콘솔이 모두 포함되며, Docker 이미지, Compose, Helm Chart도 제공합니다.
- H2, PostgreSQL, MySQL, MariaDB, Oracle, SQL Server를 지원합니다. 마이그레이션은 Liquibase가 관리하며 모든 커밋이 9개 데이터베이스 버전에서 테스트됩니다.
- 최초 기동 시 초기화 마법사가 서비스 로그의 일회용 토큰으로 플랫폼 관리자를 생성합니다.
- 클러스터 배포. 세션은 데이터베이스에 저장하고 ID는 시간 순서가 보장되는 TSID입니다.
- 완전히 새로워진 콘솔. Vue 3, Tailwind CSS, 라이트와 다크 테마, 한국어와 영어를 지원합니다.

## 신원과 조직

- 멀티 테넌시. 테넌트마다 계정, 조직, 권한 부여가 완전히 격리됩니다.
- 사용자, 부서 트리, 사용자 그룹, 직위, CSV 대량 가져오기와 내보내기.
- Argon2id 비밀번호, 설정 가능한 비밀번호 정책과 잠금, 세션 관리, TOTP 2단계 인증과 복구 코드, 민감한 작업의 재인증.
- LDAP / Active Directory와 OIDC 신원 소스, 동기화와 연합 로그인 지원.

## 권한 부여

- 리소스 카탈로그. 모듈, 메뉴, 페이지, 탭, 버튼, API, 데이터 엔터티와 필드, 그리고 그 사이의 의존 관계를 담습니다. 콘솔 자체의 페이지, 버튼, API도 카탈로그에 포함되며 동일한 권한 부여를 받습니다.
- 역할과 권한 부여. 허용과 거부, 상속, 사용자/사용자 그룹/부서/직위 기준 배정, 유효 기간.
- 데이터 권한. 조직 범위나 구조화된 조건으로 볼 수 있는 데이터 행을 제한합니다.
- 필드 권한. 역할별로 필드를 숨기거나 마스킹하거나 읽기 전용으로 만듭니다.
- 권한 설명, 사용자별 시뮬레이션, 완전한 감사 로그, 잘못된 설정에 대한 검사.

## 거버넌스

- 직무 분리. 상호 배타적인 역할은 배정, 상속, 요청 시 거부되며 이미 존재하는 충돌도 발견할 수 있습니다.
- 권한 요청. 사용자가 요청할 수 있는 역할을 요청하면 승인자가 승인한 뒤 제한된 시간 동안만 유효하며 만료 시 자동으로 회수됩니다.
- 정기 권한 검토.

## 애플리케이션 연동

- 내장 OAuth 2.1 / OpenID Connect 인증 서버. 인증 코드 + PKCE, 클라이언트 자격 증명, 새로 고침 토큰 로테이션, 서명 키 로테이션.
- 버전과 ETag를 갖춘 권한 조회 오픈 API.
- 실행 가능한 예제 애플리케이션이 함께 제공되는 Spring Boot Starter와 JavaScript SDK.

## 외부 시스템 권한

- 플러그인 기반 서비스 타입. 플러그인이 리소스 계층, 접근 타입, 마스킹, 데이터 행 필터링을 정의하며 각 플러그인은 독립적으로 로드됩니다.
- 범용 정책 편집기, Ed25519 서명이 적용된 정책 스냅샷, 에이전트 하트비트와 접근 감사.
- 예제 플러그인, HDFS 서비스 타입, Hadoop 3.5.0 NameNode 에이전트. Hive 플러그인과 다른 Hadoop 버전의 에이전트는 개발 중입니다.

## 품질

- 백만 계정 규모의 성능 벤치마크가 매일 밤 실행되며 한계를 넘으면 실패합니다.
- 정적 분석(NullAway, Error Prone, Checkstyle, PMD, SpotBugs, ArchUnit), 커버리지 기준, 풀스택 브라우저 테스트.
- 문서 사이트는 Next.js와 Tailwind CSS로 다시 만들었습니다.
