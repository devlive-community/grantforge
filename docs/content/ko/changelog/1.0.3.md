> [!NOTE]
> 이것은 재구축 이전 1.x 버전입니다(당시 이름은 AuthX). 1.x에서 업그레이드하려면 [업그레이드와 이전 버전 마이그레이션](/ko/deploy/upgrade/)을 참고하세요.

## 수정

- 메뉴 도움말 메시지가 메뉴와 일치하지 않는 문제 수정
- 페이징 데이터가 페이지 너비를 벗어나는 문제 수정
- 새 사용자를 만들 때 반응이 없는 문제 수정
- 컴파일 오류 수정
- 왼쪽 대시보드 기능을 사용할 수 없고 페이지가 하얗게 표시되는 문제 수정

## 새 기능

- JSON 유틸리티 기능 추가
- 대시보드의 사용자/로그 데이터를 집계하는 통계 모듈 추가
