> [!NOTE]
> 이것은 재구축 이전 1.x 버전입니다(당시 이름은 AuthX). 1.x에서 업그레이드하려면 [업그레이드와 이전 버전 마이그레이션](/ko/deploy/upgrade/)을 참고하세요.

## 수정

- 왼쪽 메뉴가 완전히 표시되지 않는 문제 수정
- JSON 데이터 포맷/압축 시 오른쪽 편집기 내용이 지워지지 않는 문제 수정
- 메뉴가 재귀 방식으로 캡슐화되도록 수정
- 2단계 메뉴에 아이콘이 표시되지 않는 문제 수정

## 새 기능

- 후속 기능 확장을 위해 사용자에 systemed, locked, email 필드를 추가
- 사용자 정의 헤더 정보 지원 추가
- 헤더 관리 페이지의 동적 헤더 지원
- 동적 헤더 페이징 기능 지원
- JSON을 CSV로 변환하는 도구 추가
