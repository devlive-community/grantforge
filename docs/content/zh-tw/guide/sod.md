**存取控制 → 職責分離** 設定不能由同一人同時持有的角色（如付款與審批），並檢視目前違反約束的帳號。

![職責分離](/screenshots/sod.png)

## 約束

| 設定 | 說明 |
| --- | --- |
| 互斥角色 | 2–50 個角色 |
| 每個帳號最多持有 | 預設 1，可以設為「三個裡最多兩個」 |
| 模式 | **強制**：拒絕會產生衝突的角色分配與繼承；**僅報告**：允許變更，只在衝突清單中顯示 |
| 啟用 | 停用的約束既不拒絕也不報告 |

「持有」包括所有途徑：直接分配、透過使用者群組、部門、職位取得，以及透過角色繼承取得。有效期外的分配和停用的角色不算。

## 強制的時機

強制模式下，以下變更會在儲存前檢查它所觸及的每個帳號：

- 分配角色，或修改分配的有效期、是否包含下級部門；
- 修改角色的繼承關係；
- 審批權限申請（見 [權限申請與審批](/zh-tw/guide/access-requests/)）。

只拒絕**這次變更新產生**的衝突，並提示是誰、哪些角色、違反了哪條約束；約束生效前就已經存在的衝突不會阻塞其他無關的變更，它們一直顯示在衝突清單裡，需要人工處理。

> [!WARNING]
> 把人加入使用者群組、部門或職位時不做這項檢查。透過這些途徑產生的衝突會出現在衝突清單中，請定期檢視。
