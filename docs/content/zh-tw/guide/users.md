**存取控制 → 使用者管理** 管理組織內的帳號：所屬部門、能否登入，以及重設密碼。

![使用者管理](/screenshots/users.png)

## 尋找

以使用者名稱、顯示名稱或電子郵件搜尋，依狀態（正常、已停用、已鎖定、待變更密碼）和部門篩選，可選擇是否包含下級部門。清單僅顯示你的資料權限允許看到的帳號，電子郵件等欄位可能依你的欄位權限隱藏或遮罩。

## 建立與編輯

「建立使用者」需要填寫使用者名稱（3–64 個字母、數字或 `._@-`，全平台唯一）、初始密碼、顯示名稱、電子郵件、主部門、兼職部門和職位。新帳號首次登入時必須變更密碼。

## 帳號操作

| 操作 | 效果 |
| --- | --- |
| 停用 / 啟用 | 停用後無法登入，現有工作階段立即結束 |
| 鎖定 / 解鎖 | 管理員鎖定不會自動解除，登入時會提示聯絡管理員；懷疑帳號被盜用時使用 |
| 重設密碼 | 設定新的初始密碼，使用者下次登入必須變更，現有工作階段結束 |
| 重設雙因素驗證 | 用於驗證器遺失：關閉該帳號的雙因素驗證並結束其工作階段 |
| 檢視角色 | 帳號持有的角色以及每個角色的來源（直接指派、使用者群組、部門、職位） |
| 檢視有效權限 | 見 [權限解釋、模擬與稽核](/zh-tw/guide/explain/) |
| 刪除 | 刪除帳號及其部門關聯，稽核記錄會保留 |

系統帳號（初始化時建立的管理員）和你自己的帳號不能被停用、鎖定或刪除。

## 自助註冊

預設關閉。設定 `grantforge.security.registration-enabled=true` 後，登入頁會出現「建立帳號」入口，註冊的帳號會進入 `grantforge.security.registration-tenant` 指定的租戶，是沒有任何角色的一般帳號。
