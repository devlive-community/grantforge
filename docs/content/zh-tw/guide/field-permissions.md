欄位權限決定角色的持有者如何**看到和修改**各個受控欄位。在角色列上點擊 **欄位權限** 進行設定。

![欄位權限](/screenshots/role-fields.png)

## 檢視方式

| 方式 | 效果 |
| --- | --- |
| 可見 | 顯示原值 |
| 遮罩 | 依遮罩方式部分隱藏：電子郵件（保留首字母與網域）、手機號碼（138\*\*\*5678）、證件號碼（保留前 6 後 4 碼）、保留首尾字元、全部隱藏 |
| 隱藏 | 不回傳這個欄位，清單中不顯示該欄 |

## 修改方式

| 方式 | 效果 |
| --- | --- |
| 可修改 | 可以填寫和修改 |
| 唯讀 | 表單中停用；直接呼叫 API 修改時回傳錯誤並指出是哪個欄位 |

## 合併規則

- 未設定的欄位由持有者的其他角色決定；所有角色都沒有設定時，欄位可見、可修改。
- 多個角色設定同一欄位時，取**最寬鬆**的一個（可見 > 遮罩 > 隱藏，可修改 > 唯讀）。
- 搜尋與匯出同樣遵守欄位權限：隱藏的欄位不能用來搜尋，匯出時依規則隱藏或遮罩。

## 受控欄位

受控欄位由伺服器端程式碼宣告（目前有使用者的電子郵件與最近登入時間），並在 **平台管理 → 資源目錄** 中列出它出現在哪些介面裡。業務應用程式的欄位控制可以由應用程式自己實作，規則同樣從開放 API 取得。
