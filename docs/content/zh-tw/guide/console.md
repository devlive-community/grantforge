## 版面配置

- **左側選單**按分組排列：工作空間、存取控制、資料權限、平台管理。
- **頂欄**有快速跳轉（⌘K 或 Ctrl+K，按名稱搜尋頁面）、中英文切換、淺色/深色主題和個人選單。
- **總覽**頁顯示目前租戶的帳號、部門、使用者群組與職位數量，以及工作空間成員和入門步驟。

## 選單分組

| 分組 | 選單 | 說明 |
| --- | --- | --- |
| 工作空間 | 總覽、我的申請 | 每個登入使用者都能看到 |
| 存取控制 | 使用者管理、組織架構、使用者群組、職位、匯入匯出、角色管理、職責分離、權限審批、權限覆核、線上工作階段、身分來源、稽核日誌 | 本租戶的身分與授權 |
| 資料權限 | 資料服務、政策、代理、存取稽核 | 外部資料系統（HDFS、Hive 等）的權限，見 [資料服務、政策與代理](/zh-tw/external/data-services/) |
| 平台管理 | 租戶管理、資源目錄、API 目錄、授權伺服器、目錄體檢、外掛程式 | 僅在平台租戶中可用 |

## 為什麼我的選單和別人不一樣

主控台本身就是 GrantForge 管理的一個應用程式：每個頁面和按鈕都是資源目錄裡的資源，你能看到哪些選單、哪些按鈕，完全由你的角色決定。

- 持有**租戶管理員**系統角色的人能看到本租戶的全部「存取控制」和「資料權限」選單。
- 持有**平台管理員**系統角色的人還能看到「平台管理」。
- 其他人僅看到角色授權過的頁面；一個分組裡一個頁面都沒有時，整個分組不顯示。

> [!NOTE]
> 隱藏選單僅是為了方便。伺服器端對每一次 API 呼叫都會重新檢查權限，即使直接輸入網址，沒有權限的操作也會被拒絕。

授權變更後不需要重新登入：每個回應都帶有目前權限的版本號，版本變更時主控台會自動重新載入選單。
