**存取控制 → 角色管理**：角色是一組授權的集合，指派給使用者、使用者群組、部門或職位後生效。

![角色管理](/screenshots/roles.png)

## 系統角色與自訂角色

每個租戶都有系統角色 **租戶管理員**，平台租戶還有 **平台管理員**。系統角色自動擁有其模組下的全部資源，不能修改；需要類似但更小的權限时，**複製**系統角色，再修改副本。

自訂角色有代碼（小寫字母、數字、點、連字號或底線）和名稱，可以停用：停用的角色不授予任何權限，也不透過繼承傳遞權限。

## 授權

在角色列上點擊 **授權**，開啟授權矩陣：

![授權矩陣](/screenshots/role-grants.png)

- 按應用程式切換，資源按目錄樹展開，每個資源可以選擇「允許」或「拒絕」。
- **允許一個按鈕會自動推導出它所在的頁面和它需要的介面**，不必逐一勾選。推導出的資源在矩陣裡有標記。
- **拒絕優先**，並作用於下級資源：拒絕一個頁面，頁面下的按鈕即使在別的角色裡被允許也不可用。
- 你僅能授出自己擁有的權限，避免越權。持有系統角色的人可以授出業務應用程式的任何資源。

儲存前，GrantForge 會顯示這次修改的**影響**：哪些資源會變為可用或不可用、有多少使用者持有這個角色。

## 繼承

點擊 **繼承**，選擇這個角色繼承的角色：它會得到被繼承角色允許和拒絕的一切，以及它們再繼承的角色。繼承不能成環，你僅能繼承自己擁有的權限。適合「經理 = 員工 + 審批」這種疊加關係。

## 指派

點擊 **指派**，把角色指派給：

| 物件 | 說明 |
| --- | --- |
| 使用者 | 直接給某個帳號 |
| 使用者群組 | 群組內所有成員獲得角色 |
| 部門 | 部門成員獲得角色，可選「包含下級部門」 |
| 職位 | 任該職位的人獲得角色 |

每個指派可以設定**生效時間**和**截止時間**，到期自動失效，適合臨時授權。也可以透過 [權限申請與審批](/zh-tw/guide/access-requests/) 讓使用者自己申請限時角色。

指派與授權受 [職責分離](/zh-tw/guide/sod/) 約束：若某個指派會讓某人同時持有互斥角色，該指派會被拒絕。

## 資料權限與欄位權限

角色列上的 **資料權限** 與 **欄位權限** 分別決定持有者能看到哪些列、如何看到和修改哪些欄位，見 [資料權限](/zh-tw/guide/data-permissions/) 與 [欄位權限](/zh-tw/guide/field-permissions/)。

## 複製與刪除

**複製** 會連同授權、資料權限與欄位權限一起複製。刪除角色會同時刪除它的指派、授權與政策，無法還原。
