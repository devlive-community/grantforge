## 資源目錄

**平台管理 → 資源目錄** 維護各應用程式的資源樹。主控台自身（`grantforge-console`）是內建應用程式，它的頁面、按鈕與 API 在啟動時自動登記，不能刪除。

![資源目錄](/screenshots/resources.png)

- **應用程式**：新增、編輯、刪除業務應用程式；有客戶端或資源的應用程式不能刪除。
- **資源**：模組、選單、頁面、標籤、按鈕、API、資料實體與欄位。類型決定可以放在哪裡：按鈕只能在頁面或標籤下，欄位只能在資料實體下。資源可以拖曳調整位置，最多 15 層。
- **狀態**：可以隱藏或停用資源；缺少權限時，可以選擇按鈕為「隱藏」或「停用」。
- **相依**：按鈕「需要」它呼叫的 API，頁面「需要」它載入資料的 API；授權時相依會被一併推導出來，詳情頁以圖形呈現相依關係。
- **OAuth 用戶端**：為業務應用程式註冊用戶端，見 [OAuth 2.1 與 OpenID Connect](/zh-tw/integration/oauth/)。
- **欄位**：選取欄位時顯示它出現在哪些介面中（回傳或接收）。

## API 目錄

**平台管理 → API 目錄** 列出伺服器端啟動時自動登記的全部介面及其存取要求：公開、登入即可，或需要某個權限代碼。需授權的介面依權限代碼歸入資源目錄，角色授權時引用這些權限。介面新增、下線或權限代碼變更時會列為「待確認的變更」，確認後更新目錄。

![API 目錄](/screenshots/apis.png)

## 目錄健康檢查

**平台管理 → 目錄健康檢查** 找出已悄悄失效的設定：不生效的授權、無法運作的按鈕（缺少需要的 API）、沒有人能呼叫的 API 與中斷的相依。健康檢查僅讀取資料，不做任何變更。
