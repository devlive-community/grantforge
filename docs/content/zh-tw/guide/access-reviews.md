**存取控制 → 權限覆核**：定期覆核誰持有哪些角色，覆核人逐項決定保留或撤銷，本輪完成時移除被撤銷的分配。

![權限覆核](/screenshots/access-reviews.png)

## 覆核計畫

| 設定 | 說明 |
| --- | --- |
| 名稱、說明 | 例如「財務角色季度覆核」 |
| 角色 | 要覆核的角色，每輪會列出它們目前的全部分配 |
| 每輪時長 | 1–90 天，到期自動完成本輪 |
| 重複間隔 | 留空僅手動開始；否則依間隔自動開始下一輪 |
| 未覆核的項目 | 本輪結束時沒有決定的項目：**保留**或**撤銷** |
| 啟用 | 僅影響是否依計畫自動開始 |

## 一輪覆核

1. 點擊 **立即開始**，或等計畫自動開始。GrantForge 為每個分配產生一個覆核項目（系統帳號的系統角色除外）。
2. 覆核人在本輪中逐項或批次選擇 **保留** 或 **撤銷**，撤銷可以填寫說明；決定可以在本輪結束前撤回。
3. 不能覆核自己透過直接分配、使用者群組、部門或職位取得的角色。
4. 管理員可以 **完成本輪**（套用全部決定，未決定的依計畫設定處理），也可以 **取消本輪**（不做任何變更）。到期未完成的輪次會自動完成。

被撤銷的分配在本輪完成時刪除。每一步都記錄在稽核日誌中，適合作為內控稽核的留痕。
