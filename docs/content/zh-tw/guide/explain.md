## 有效權限

在 **使用者管理** 的使用者列上點擊「查看有效權限」，可以看到該使用者現在能用的一切：角色、選單與按鈕、API、資料範圍與受限欄位。

![有效權限](/screenshots/user-permissions.png)

點擊任一項目的 **說明**，GrantForge 會回答「為什麼能用」：由哪個角色、經過哪些分配（直接、使用者群組、部門、職位）與哪些資源推導而得；不能用時說明是沒有授權，還是被某條拒絕規則擋住。

## 模擬變更

在有效權限中開啟 **模擬變更**：假設為該使用者新增或移除某些角色，看看會多出或失去哪些選單、按鈕和 API。模擬只是計算，不會儲存任何東西，適合在調整權限前確認效果。

## 稽核日誌

**存取控制 → 稽核日誌** 記錄誰在什麼時候做了什麼：登入、授權變更、管理操作與被拒絕的呼叫。

![稽核日誌](/screenshots/audit.png)

- 依事件、結果、操作者、物件與時間篩選，結果可以匯出為 CSV。
- 每筆事件帶有來源 IP、瀏覽器與請求 ID，請求 ID 與伺服器端日誌對應。
- 僅顯示你的資料權限允許看到的事件。
- 稽核預設保留 365 天（`grantforge.audit.retention`），可以設定在刪除前歸檔到目錄。

記錄的事件包括：登入成功與失敗、鎖定、登出、工作階段結束、密碼修改，租戶、部門、使用者、使用者群組、職位的變更，資源與 API 目錄變更，角色、授權、繼承、分配的變更，資料與欄位政策變更，職責分離、權限申請與覆核的每一步，身分來源與 OAuth 用戶端的變更，以及被拒絕的 API 呼叫。
