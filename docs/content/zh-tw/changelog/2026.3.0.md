2026.3.0 將外部系統權限擴展到 Apache Pulsar、Apache Solr、ClickHouse、PostgreSQL 與 OpenSearch。Pulsar 與 Solr 代理在系統內部判定每個請求；ClickHouse、PostgreSQL 與 OpenSearch 代理執行在系統旁邊，讓系統自身的存取控制與策略保持一致，由系統自己檢查每個請求。完整變更見 [GitHub 比較](https://github.com/devlive-community/grantforge/compare/v2026.2.0...v2026.3.0)。

## Apache Pulsar

- Pulsar 服務外掛：租戶、命名空間、主題、主題下的訂閱與叢集，使用 Pulsar 的 produce、consume、functions、sources、sinks、packages 以及主題、命名空間與租戶的管理存取類型；支援權杖、密碼、OAuth 2.0 用戶端憑證或 TLS 用戶端憑證登入；見 [Apache Pulsar](/zh-tw/plugins/pulsar/)。
- Broker 授權提供者：依序在租戶、命名空間、主題與訂閱上判定每次檢查，並支援用戶端位址條件；叢集上的 admin 使角色成為 Pulsar 超級使用者，透過 Pulsar 自身授權會被拒絕；見 [Apache Pulsar 代理](/zh-tw/external/pulsar-agent/)。
- 整合測試涵蓋 Pulsar 3.0.17、3.3.9、4.0.14 與 4.2.5。

## Apache Solr

- Solr 服務外掛：集合、集合內的請求路徑（如 `/select`、`/export`，策略可以允許集合而拒絕某個處理器）以及叢集；支援基本認證或 JSON Web Token 登入；見 [Apache Solr](/zh-tw/plugins/solr/)。
- 節點授權外掛：依 Solr 基於規則的外掛的方式對請求分類，並在集合與請求路徑上逐一判定；Collections API 請求需要對其涉及的每個集合擁有 `admin_collection`，JSON Web Token 中經過驗證的角色視為使用者群組；見 [Apache Solr 代理](/zh-tw/external/solr-agent/)。
- 整合測試在 Solr 9 的安全管理員下涵蓋 Solr 9.8.1、9.10.1、9.11.0 與 10.0.0 的 SolrCloud 節點。

## ClickHouse

- ClickHouse 服務外掛：資料庫、資料表、欄與伺服器；讀寫依欄判定，資料表、資料庫與伺服器的操作使用各自的存取類型，均不是權限群組，因此策略不會給出超出其所列的權限；見 [ClickHouse](/zh-tw/plugins/clickhouse/)。
- 執行在伺服器旁的代理：為每個使用者維護一個恰好包含策略所授權限的角色，並為每個列過濾器維護一條列策略；在整個資料庫上允許且其下沒有任何限制的存取類型會授予在資料庫上，新資料表立即可用；見 [ClickHouse 代理](/zh-tw/external/clickhouse-agent/)。
- 存取記錄來自 `system.query_log`；GrantForge 之外給出了策略所拒絕權限的授權會被回報。整合測試涵蓋 ClickHouse 24.8、25.3、25.8、26.3 與 26.8。

## PostgreSQL

- PostgreSQL 服務外掛：資料庫、結構描述、資料表與檢視以及欄，權限在 PostgreSQL 授予它們的層級上判定；支援密碼或 TLS 用戶端憑證登入，並使用 libpq 的 TLS 模式；見 [PostgreSQL](/zh-tw/plugins/postgresql/)。
- 執行在伺服器旁的代理：在每個資料庫中為每個使用者維護一個角色，細化到欄，並附帶所需的 `CONNECT`、結構描述 `USAGE` 與 serial 序列，每個資料庫的變更在一個交易中完成；列過濾器成為限制性列安全策略，只會收窄存取；見 [PostgreSQL 代理](/zh-tw/external/postgresql-agent/)。
- 存取記錄來自 pgaudit 寫入的伺服器日誌。整合測試涵蓋 PostgreSQL 15、16、17 與 18。

## OpenSearch

- OpenSearch 服務外掛：索引與資料串流、其欄位以及叢集；每種存取類型都是安全外掛的一個動作群組；遮罩成為其遮罩欄位，列過濾器成為其文件層級安全；見 [OpenSearch](/zh-tw/plugins/opensearch/)。
- 執行在叢集旁的代理：為每個使用者維護一個僅對應到該使用者的角色，以 JSON 修補寫入，安全外掛會在整個叢集生效；凡是所有策略對其判定一致的索引模式都保持為模式，之後建立的索引立即可達；見 [OpenSearch 代理](/zh-tw/external/opensearch-agent/)。
- 存取記錄來自安全外掛的稽核日誌；GrantForge 之外給出了策略所拒絕權限的角色會被回報。整合測試涵蓋 OpenSearch 2.19、3.3、3.6 與 3.9。

## 策略引擎與代理

- 策略引擎可以判斷資源之下是否有內容會對某使用者和某存取作出不同判定，因此以系統自身術語授權的代理可以整體授予容器，例如資料庫中的所有資料表。
- 代理快照除存取策略外，還提供遮罩與列過濾策略以及其中涉及的使用者。

## 文件與發布

- Pulsar、Solr、ClickHouse、PostgreSQL 與 OpenSearch 的外掛和代理已提供全部 11 種語言的文件，各 README 均列出它們及整合測試驗證的版本。
- 文件網站的捲軸在淺色與深色主題下都跟隨網站配色。
- GitHub 發布以版本標籤作為標題。

## 問題修正

- Pulsar 外掛將拒絕連線的 Broker 回報為無法存取。
- Solr 代理基於 Solr 9.10.1 建置，該版本修正了早期版本的安全公告。
- PostgreSQL 代理可以解析伺服器日誌時間中的時區縮寫，如 `CEST`。
- OpenSearch 代理將 SLF4J 保留在自己的 jar 內，打包它的伺服器保持自身的日誌設定。
- 主控台、SDK 與文件網站將 vite、vitest、undici 與 dompurify 升級到修正 npm 安全公告的版本。
