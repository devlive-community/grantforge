2026.1.0 將 2026.0.0 的外部系統權限擴展到 HDFS、ZooKeeper 與 MySQL，並提供執行策略的代理；主控台與文件支援十一種語言。完整變更請見 [GitHub 比較](https://github.com/devlive-community/grantforge/compare/v2026.0.0...v2026.1.0)。

## Apache Hadoop HDFS

- 適用於 Hadoop 2.7、2.10、3.2、3.3、3.4 與 3.5 的分版本 NameNode 代理，共用一個原生模組；請見 [HDFS NameNode 代理](/zh-tw/external/hdfs-agent/)。
- 所有 Hadoop 版本線支援 Kerberos，支援跨多個領域的叢集，查詢之間保留登入狀態；`swebhdfs` 依服務設定信任。
- 已在 Hadoop 2.10 至 3.5 的 Kerberos 叢集及自動 HA 容錯移轉下驗證。
- 代理透過 Hadoop 指標回報決策，並固定其執行的策略快照。

## Apache ZooKeeper

- ZooKeeper 服務外掛，支援 TLS 工作階段與分頁的 znode 查詢。
- 伺服器端代理，依服務策略判定標記 ACL；請見 [ZooKeeper 代理](/zh-tw/external/zookeeper-agent/)。

## MySQL

- MySQL 服務外掛：資料庫、資料表、欄位查詢，以及存取、遮罩與列篩選策略；請見 [MySQL](/zh-tw/plugins/mysql/)。
- MySQL 代理：逐欄檢查陳述式、遮罩取值並篩選列；請見 [MySQL 代理](/zh-tw/external/mysql-agent/)。

## 外掛與策略

- 代理執行遮罩與列篩選策略。
- 策略編輯器可瀏覽服務目錄以選擇路徑。
- 查詢失敗時說明原因，如無法連線、登入被拒或缺少權限。
- 停用外掛前先列出它影響的內容。
- 產品外掛在文件中有獨立的欄目。

## 主控台

- 十一種介面語言：簡體與繁體中文、英文、日文、韓文、俄文、德文、法文、西班牙文、巴西葡萄牙文與義大利文，可從清單中選擇，也可在初始化頁面選擇。
- 掃描 QR 碼設定兩步驟登入；登入表單列出可登入的目錄。
- 帳號頁依分頁拆分，每個分頁有自己的位址；稽核日誌與 API 目錄使用與其他清單相同的分頁器。
- 列操作改為帶提示的圖示按鈕；對話框雙向動畫並忽略背景點擊；日期改用日曆選擇器；資源樹可搜尋。
- 表單驗證在每個出錯欄位旁的提示中標出。

## 文件

- 文件站同樣提供十一種語言，並支援搜尋韓文與西里爾文。

## 問題修正

- MySQL：代理的 SLF4J 綁定不再進入伺服器日誌；身分對應宣告為對應。
- ZooKeeper：升級 Netty 以消除安全公告，並強化 TLS 工作階段。
- 服務查詢失敗以用戶端錯誤回報；內建外掛回報產品版本。
- 對話框、驗證提示、捲動與資料服務表單的多項主控台修正。
