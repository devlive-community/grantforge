2026.2.0 將 2026.1.0 的外部系統權限擴展到 Apache Hive、Apache Kafka、Apache HBase、Trino 與 Apache Hadoop YARN，並提供執行這些權限的代理。完整變更見 [GitHub 比較](https://github.com/devlive-community/grantforge/compare/v2026.1.0...v2026.2.0)。

## Apache Hive

- Hive 服務外掛：資料庫、資料表、欄位、UDF、URL、HiveServer2 服務與複寫，存取類型與 Apache Ranger 一致；見 [Apache Hive](/zh-tw/plugins/hive/)。
- HiveServer2 代理：檢查每條陳述式，過濾 `SHOW` 結果，遮蔽欄位並過濾列；見 [Hive 代理](/zh-tw/external/hive-agent/)。
- 暫存 UDF 在全域範圍內僅授予 `tempudfadmin`，與 Apache Ranger 一致，因為它們會執行使用者指定的程式碼。

## Apache Kafka

- Kafka 服務外掛：主題、消費群組、交易 ID、叢集、委派權杖與 SCRAM 使用者，使用 Kafka 自身的存取類型與蘊含關係；見 [Apache Kafka](/zh-tw/plugins/kafka/)。
- Broker 與 Controller 授權器：檢查每個請求；見 [Kafka 代理](/zh-tw/external/kafka-agent/)。

## Apache HBase

- HBase 服務外掛：命名空間、資料表、欄位族與欄位，以及針對整個叢集操作的全域範圍；見 [Apache HBase](/zh-tw/plugins/hbase/)。
- Master 與 RegionServer 協處理器：檢查操作，僅回傳使用者可讀的欄位，並隱藏使用者無權看到的內容；見 [HBase 代理](/zh-tw/external/hbase-agent/)。

## Trino

- Trino 服務外掛：目錄、結構描述、資料表、欄位、函式、程序與工作階段屬性；見 [Trino](/zh-tw/plugins/trino/)。
- 兩個系統存取控制：分別適用於 Trino 470 至 478 與 479 及以後版本，檢查查詢、過濾列並遮蔽欄位；見 [Trino 代理](/zh-tw/external/trino-agent/)。

## Apache Hadoop YARN

- YARN 服務外掛：佇列與應用程式，使用 YARN 的 `submit_app` 與 `admin_queue` 存取類型；見 [Apache Hadoop YARN](/zh-tw/plugins/yarn/)。
- ResourceManager 授權提供者：依策略決定提交、佇列與叢集管理，並支援用戶端位址條件；見 [YARN 代理](/zh-tw/external/yarn-agent/)。

## 策略引擎與代理

- 策略可判定資源之下的存取：列出資料庫時會計入使用者的資料表策略；新增的 `_any` 存取類型在資源或其下任一存取被允許時即放行。
- 策略可判斷使用者能否對某層級的任一資源執行操作，與 Kafka 在冪等生產者寫入前的詢問相同。
- 代理將時間窗口內相同的允許存取合併為一筆稽核事件，附帶次數與最後一次的時間；拒絕則立即記錄。
- 代理可以用系統自身的術語展示存取策略。
- 外掛 API 1.2.0 為所有外掛統一提供 Kerberos realm，不再相互覆寫 `krb5.conf`。

## 文件與發布

- YARN、Hive、Kafka、HBase 與 Trino 的外掛和代理已提供全部 11 種語言的文件。
- README 列出了支援的元件及整合測試驗證的版本。
- 發布標籤會執行完整 CI，發布會等待該次執行結束；發布套件並行建置；npm 透過可信發布（trusted publishing）發布。
- 缺少發布日誌的版本會在打標籤時被拒絕；CI 在一次 Java 檢查通過後，只執行與變更相關的工作。

## 問題修正

- 種子資料寫入後才準備 PostgreSQL 索引，使計時的 API 呼叫執行在已分析的資料表上。
- ZooKeeper 代理的 jar 測試在打包之後執行。
- Maven 部署跳過整合測試；先前 HDFS 3.2 代理的 forked JVM 逾時導致 GitHub Packages 部署失敗。
- npm 套件宣告了儲存庫，使 npm 能夠驗證其 provenance。
