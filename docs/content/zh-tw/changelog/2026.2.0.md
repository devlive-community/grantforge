2026.2.0 將 2026.1.0 的外部系統權限擴展到 Apache Hive、Apache Kafka、Apache HBase、Trino 與 Apache Hadoop YARN，每個系統都有服務外掛與執行策略的代理。完整變更見 [GitHub 比較](https://github.com/devlive-community/grantforge/compare/v2026.1.0...v2026.2.0)。

## Apache Hive

- Hive 服務外掛：資料庫、資料表、欄位與 UDF 的查詢，支援密碼或 Kerberos 登入；見 [Apache Hive](/zh-tw/plugins/hive/)。
- HiveServer2 代理：對每條陳述式做授權，過濾 `SHOW` 結果，遮罩欄位並過濾列；見 [Hive 代理](/zh-tw/external/hive-agent/)。
- 臨時 UDF 僅在全域範圍內授予 `tempudfadmin`，與 Apache Ranger 一致，因為它會執行使用者指定的程式碼。

## Apache Kafka

- Kafka 服務外掛：主題、消費者群組、交易 ID 與使用者的查詢，支援 PLAIN、SCRAM 或 Kerberos，可使用明文或 TLS；見 [Apache Kafka](/zh-tw/plugins/kafka/)。
- Broker 與 Controller 授權器：檢查每個請求，將策略顯示為唯讀 ACL，並將重複的存取合併為一筆稽核事件；見 [Kafka 代理](/zh-tw/external/kafka-agent/)。

## Apache HBase

- HBase 服務外掛：命名空間、資料表與欄族的查詢，透過 ZooKeeper 或引導伺服器連線，支援簡單登入或 Kerberos；見 [Apache HBase](/zh-tw/plugins/hbase/)。
- Master 與 RegionServer 協處理器：在每個範圍檢查操作、讀取與寫入，只回傳使用者可讀的欄位，並隱藏使用者無權使用的內容；見 [HBase 代理](/zh-tw/external/hbase-agent/)。

## Trino

- Trino 服務外掛：目錄、結構描述、資料表、欄位與工作階段屬性的查詢，支援密碼、JSON Web Token 或基於 TLS 的 Kerberos 登入；見 [Trino](/zh-tw/plugins/trino/)。
- 兩個系統存取控制：分別面向 Trino 470 至 478 與 479 及以後版本，用於檢查查詢、只列出使用者可使用的物件、過濾列並遮罩欄位；後者另外檢查資料表分支與檢視重新整理；見 [Trino 代理](/zh-tw/external/trino-agent/)。

## Apache Hadoop YARN

- YARN 服務外掛：可連線單一 ResourceManager 或高可用的一對，支援簡單登入或 Kerberos，查詢佇列與應用程式名稱；見 [Apache Hadoop YARN](/zh-tw/plugins/yarn/)。
- ResourceManager 中的授權提供者：依策略決定提交、佇列與叢集管理權限，並支援用戶端位址條件；見 [YARN 代理](/zh-tw/external/yarn-agent/)。

## 策略引擎與代理

- 策略可決定對某一層級中任一資源的存取，也可決定對某資源之下內容的存取，因此列出資料庫時會計入使用者的資料表策略。
- 逐請求檢查的代理會將一個時間窗口內相同的允許存取合併為一筆稽核事件，附帶次數與最後時間；拒絕存取則立即記錄。
- 代理可以用所在系統自己的術語展示其存取策略。

## 文件與發佈

- YARN、Hive、Kafka、HBase 與 Trino 的外掛和代理文件已提供十一種語言版本。
- README 列出了支援的元件，以及整合測試驗證過的版本。
- CI 在一次 Java 閘門之後只執行變更所需的工作，並拒絕缺少發佈日誌的標籤。

## 問題修復

- 種子資料寫入後再準備 PostgreSQL 索引，使計時的 API 呼叫基於已分析的資料表。
- ZooKeeper 代理的 jar 測試在打包之後執行。
