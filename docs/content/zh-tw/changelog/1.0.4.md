> [!NOTE]
> 這是重構前的 1.x 版本（當時名為 AuthX）。從 1.x 升級請參閱 [升級與舊版本遷移](/zh-tw/deploy/upgrade/)。

## 修復

- 修復左側選單未顯示完整
- 修復格式化/壓縮 JSON 資料未清空右側編輯器內容
- 修改選單使用遞迴模式進行封裝
- 修復二級選單未顯示圖示

## 新功能

- 新增使用者 systemed、locked、email 欄位用於擴展後續功能
- 新增支援自訂表頭資訊
- 支援表頭管理頁面動態表頭
- 支援動態表頭分頁功能
- 新增 JSON 轉 CSV 工具
