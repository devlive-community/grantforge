> [!NOTE]
> 這是重構前的 1.x 版本（當時名為 AuthX）。從 1.x 升級請參閱 [升級與舊版本遷移](/zh-tw/deploy/upgrade/)。

## 修復

- 選單提示訊息和選單不符合
- 分頁資料超出了頁面寬度
- 新建使用者的時候沒反應
- 編譯出錯
- 左側儀表板功能無法使用，頁面一片空白

## 新功能

- 增加 JSON 小工具功能
- 新增統計模組，統計儀表板使用者/日誌資料
