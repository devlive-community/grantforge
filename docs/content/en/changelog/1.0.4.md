> [!NOTE]
> This is a pre-rebuild 1.x version (then named AuthX). To upgrade from 1.x, see [Upgrading and legacy version migration](/en/deploy/upgrade/).

## Fixes

- Fixed the left menu not being fully displayed
- Fixed the right editor not being cleared when formatting/minifying JSON data
- Changed menus to be encapsulated using a recursive pattern
- Fixed icons not showing for second-level menu items

## New Features

- Added systemed, locked, and email user fields for future feature extension
- Added support for custom table header information
- Added dynamic headers on the table header management page
- Added pagination for dynamic headers
- Added a JSON-to-CSV tool
