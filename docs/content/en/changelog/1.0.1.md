## Fixes

- Creating content gave no clear prompt message
- Pagination stopped working in menu management after selecting a category
- After selecting an API type for a new menu, the parent menu type did not change according to the selection
- Select boxes on the new-menu page clashed with the theme
- Pages were not fully internationalized
- The left menu could not navigate to a single menu item
- Path addresses added to system APIs could not be authorized, showing `this is not active token`

## New Features

- Audit log types
- User permission assignment
- Audit logs
- User management
