2026.2.0 extends the external system permissions of 2026.1.0 to Apache Hive, Apache Kafka, Apache HBase, Trino and Apache Hadoop YARN, each with a service plug-in and an agent that enforces its policies. The complete list of changes is in the [GitHub comparison](https://github.com/devlive-community/grantforge/compare/v2026.1.0...v2026.2.0).

## Apache Hive

- A Hive service plug-in: database, table, column and UDF lookup, signing in with a password or Kerberos; see [Apache Hive](/en/plugins/hive/).
- A HiveServer2 agent that authorizes every statement, filters `SHOW` results, masks columns and filters rows; see the [Hive agent](/en/external/hive-agent/).
- Temporary UDFs are granted at the global scope only to `tempudfadmin`, as Apache Ranger does, since they run code of the user's choosing.

## Apache Kafka

- A Kafka service plug-in: topic, consumer group, transactional ID and user lookup, signing in with PLAIN, SCRAM or Kerberos over plaintext or TLS; see [Apache Kafka](/en/plugins/kafka/).
- A broker and controller authorizer that checks every request, shows policies as read-only ACLs and folds repeated accesses into one audit event; see the [Kafka agent](/en/external/kafka-agent/).

## Apache HBase

- An HBase service plug-in: namespace, table and column family lookup, through ZooKeeper or bootstrap servers, simply or with Kerberos; see [Apache HBase](/en/plugins/hbase/).
- A master and region server coprocessor that checks operations, reads and writes at every scope, returns only the columns a user may read and hides what a user may not use; see the [HBase agent](/en/external/hbase-agent/).

## Trino

- A Trino service plug-in: catalog, schema, table, column and session property lookup, signing in with a password, a JSON web token or Kerberos over TLS; see [Trino](/en/plugins/trino/).
- Two system access controls, one for Trino 470 to 478 and one for Trino 479 and later, that check queries, list only what a user may use, filter rows and mask columns; the later one also checks table branches and view refreshes; see the [Trino agent](/en/external/trino-agent/).

## Apache Hadoop YARN

- A YARN service plug-in: queue and application name lookup against one ResourceManager or a highly available pair, simply or with Kerberos; see [Apache Hadoop YARN](/en/plugins/yarn/).
- An authorization provider in the ResourceManagers that decides submission, queue and cluster administration by policy, with client-address conditions; see the [YARN agent](/en/external/yarn-agent/).

## Policy engine and agents

- Policies decide access to any resource of a level, and to what lies below a resource, so that listing a database counts a user's table policies.
- Agents that check every request fold identical allowed accesses of a time window into one audit event with a count and the moment of the last one; refusals are recorded at once.
- Agents can show their access policies in the system's own terms.

## Documentation and release

- The YARN, Hive, Kafka, HBase and Trino plug-ins and agents are documented in all eleven languages.
- The README lists the supported components and the versions the integration tests verify.
- CI runs only the jobs a change needs after one Java gate, and refuses a tag without its release log.

## Fixes

- PostgreSQL indexes are prepared after seeding, so timed API calls run on analyzed tables.
- The ZooKeeper agent's jar tests run after packaging.
