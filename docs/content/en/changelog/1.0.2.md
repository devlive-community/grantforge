## Fixes

- Menu functions could not be assigned
- A blank page appeared at the top
- Some logs in log management could not show their details
- Menu request methods contained duplicate data
- Setting an icon on a new menu did not change the page menu icon
- The usage location of the new menu feature was not shown in detail
- Tooltips were added for new menus, but their usage location could not be found
- Left menu icons in the system could not be selected explicitly

## New Features

- Added icon type management
- Added icon usages
- Added icon library management
