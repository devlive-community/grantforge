2026.1.0 把 2026.0.0 的外部系统权限扩展到 HDFS、ZooKeeper 与 MySQL，并提供执行策略的代理；控制台与文档支持十一种语言。完整变更见 [GitHub 对比](https://github.com/devlive-community/grantforge/compare/v2026.0.0...v2026.1.0)。

## Apache Hadoop HDFS

- 面向 Hadoop 2.7、2.10、3.2、3.3、3.4 与 3.5 的分版本 NameNode 代理，共用一个原生模块；见 [HDFS NameNode 代理](/external/hdfs-agent/)。
- 所有 Hadoop 版本线支持 Kerberos，支持跨多个域的集群，查询之间保留登录状态；`swebhdfs` 按服务配置信任。
- 已在 Hadoop 2.10 至 3.5 的 Kerberos 集群及自动 HA 故障切换下验证。
- 代理通过 Hadoop 指标上报决策，并固定其执行的策略快照。

## Apache ZooKeeper

- ZooKeeper 服务插件，支持 TLS 会话与分页的 znode 查询。
- 服务器端代理，依据服务策略判定标记 ACL；见 [ZooKeeper 代理](/external/zookeeper-agent/)。

## MySQL

- MySQL 服务插件：数据库、表、列查询，以及访问、脱敏与行过滤策略；见 [MySQL](/plugins/mysql/)。
- MySQL 代理：按列检查语句、脱敏取值并过滤行；见 [MySQL 代理](/external/mysql-agent/)。

## 插件与策略

- 代理执行脱敏与行过滤策略。
- 策略编辑器可浏览服务目录来选择路径。
- 查询失败时说明原因，如无法连接、登录被拒或缺少权限。
- 停用插件前先列出它影响的内容。
- 产品插件在文档中有独立的栏目。

## 控制台

- 十一种界面语言：简体与繁体中文、英语、日语、韩语、俄语、德语、法语、西班牙语、巴西葡萄牙语与意大利语，可从列表中选择，也可在初始化页面选择。
- 扫描二维码设置两步登录；登录表单列出可登录的目录。
- 账号页按标签页拆分，每个标签页有自己的地址；审计日志与 API 目录使用与其他列表相同的分页器。
- 行操作改为带提示的图标按钮；对话框双向动画并忽略背景点击；日期改用日历选择器；资源树可搜索。
- 表单校验在每个出错字段旁的提示中标出。

## 文档

- 文档站同样提供十一种语言，并支持搜索韩文与西里尔文。

## 问题修复

- MySQL：代理的 SLF4J 绑定不再进入服务器日志；身份映射声明为映射。
- ZooKeeper：升级 Netty 以消除安全公告，并加固 TLS 会话。
- 服务查询失败按客户端错误报告；内置插件报告产品版本。
- 对话框、校验提示、滚动与数据服务表单的多项控制台修复。
