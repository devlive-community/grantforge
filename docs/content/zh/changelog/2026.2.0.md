2026.2.0 将 2026.1.0 的外部系统权限扩展到 Apache Hive、Apache Kafka、Apache HBase、Trino 与 Apache Hadoop YARN，并提供执行这些权限的代理。完整变更见 [GitHub 对比](https://github.com/devlive-community/grantforge/compare/v2026.1.0...v2026.2.0)。

## Apache Hive

- Hive 服务插件：数据库、表、列、UDF、URL、HiveServer2 服务与复制，访问类型与 Apache Ranger 一致；见 [Apache Hive](/plugins/hive/)。
- HiveServer2 代理：检查每条语句，过滤 `SHOW` 结果，屏蔽列并过滤行；见 [Hive 代理](/external/hive-agent/)。
- 临时 UDF 在全局范围内仅授予 `tempudfadmin`，与 Apache Ranger 一致，因为它们会运行用户指定的代码。

## Apache Kafka

- Kafka 服务插件：主题、消费组、事务 ID、集群、委派令牌与 SCRAM 用户，使用 Kafka 自身的访问类型与蕴含关系；见 [Apache Kafka](/plugins/kafka/)。
- Broker 与 Controller 授权器：检查每个请求；见 [Kafka 代理](/external/kafka-agent/)。

## Apache HBase

- HBase 服务插件：命名空间、表、列族与列，以及针对整个集群操作的全局范围；见 [Apache HBase](/plugins/hbase/)。
- Master 与 RegionServer 协处理器：检查操作，仅返回用户可读的列，并隐藏用户无权看到的内容；见 [HBase 代理](/external/hbase-agent/)。

## Trino

- Trino 服务插件：目录、模式、表、列、函数、过程与会话属性；见 [Trino](/plugins/trino/)。
- 两个系统访问控制：分别适用于 Trino 470 至 478 与 479 及以后版本，检查查询，过滤行并屏蔽列；见 [Trino 代理](/external/trino-agent/)。

## Apache Hadoop YARN

- YARN 服务插件：队列与应用，使用 YARN 的 `submit_app` 与 `admin_queue` 访问类型；见 [Apache Hadoop YARN](/plugins/yarn/)。
- ResourceManager 授权提供者：按策略决定提交、队列与集群管理，并支持客户端地址条件；见 [YARN 代理](/external/yarn-agent/)。

## 策略引擎与代理

- 策略可判定资源之下的访问：列出数据库时会计入用户的表策略；新增的 `_any` 访问类型在资源或其下任一访问被允许时即放行。
- 策略可判断用户能否对某层级的任一资源执行操作，Kafka 在幂等生产者写入前即如此询问。
- 代理将时间窗口内相同的允许访问合并为一条审计事件，附带次数与最后一次的时间；拒绝则立即记录。
- 代理可以用系统自身的术语展示访问策略。
- 插件 API 1.2.0 为所有插件统一提供 Kerberos realm，不再相互覆盖 `krb5.conf`。

## 文档与发布

- YARN、Hive、Kafka、HBase 与 Trino 的插件和代理已提供全部 11 种语言的文档。
- README 列出了受支持的组件及集成测试验证的版本。
- 发布标签会运行完整 CI，发布等待该次运行结束；发布包并行构建；npm 通过可信发布（trusted publishing）发布。
- 缺少发布日志的版本会被拒绝打标签；CI 在一次 Java 检查通过后，只运行与变更相关的任务。

## 问题修复

- 种子数据写入后再准备 PostgreSQL 索引，使计时的 API 调用运行在已分析的表上。
- ZooKeeper 代理的 jar 测试在打包之后运行。
- Maven 部署跳过集成测试；此前 HDFS 3.2 代理的 forked JVM 超时导致 GitHub Packages 部署失败。
- npm 包声明了仓库，使 npm 能够验证其 provenance。
