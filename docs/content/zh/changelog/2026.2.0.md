2026.2.0 将 2026.1.0 的外部系统权限扩展到 Apache Hive、Apache Kafka、Apache HBase、Trino 与 Apache Hadoop YARN，每个系统都有服务插件和执行策略的代理。完整变更见 [GitHub 对比](https://github.com/devlive-community/grantforge/compare/v2026.1.0...v2026.2.0)。

## Apache Hive

- Hive 服务插件：数据库、表、列与 UDF 的查询，支持密码或 Kerberos 登录；见 [Apache Hive](/plugins/hive/)。
- HiveServer2 代理：对每条语句做授权，过滤 `SHOW` 结果，屏蔽列并过滤行；见 [Hive 代理](/external/hive-agent/)。
- 临时 UDF 仅在全局范围内授予 `tempudfadmin`，与 Apache Ranger 一致，因为它会运行用户指定的代码。

## Apache Kafka

- Kafka 服务插件：主题、消费者组、事务 ID 与用户的查询，支持 PLAIN、SCRAM 或 Kerberos，可使用明文或 TLS；见 [Apache Kafka](/plugins/kafka/)。
- Broker 与 Controller 授权器：检查每个请求，将策略显示为只读 ACL，并将重复的访问合并为一条审计事件；见 [Kafka 代理](/external/kafka-agent/)。

## Apache HBase

- HBase 服务插件：命名空间、表与列族的查询，通过 ZooKeeper 或引导服务器连接，支持简单登录或 Kerberos；见 [Apache HBase](/plugins/hbase/)。
- Master 与 RegionServer 协处理器：在每个范围检查操作、读取与写入，只返回用户可读的列，并隐藏用户无权使用的内容；见 [HBase 代理](/external/hbase-agent/)。

## Trino

- Trino 服务插件：目录、模式、表、列与会话属性的查询，支持密码、JSON Web Token 或基于 TLS 的 Kerberos 登录；见 [Trino](/plugins/trino/)。
- 两个系统访问控制：分别面向 Trino 470 至 478 和 479 及以后版本，用于检查查询、只列出用户可使用的对象、过滤行并屏蔽列；后者还检查表分支与视图刷新；见 [Trino 代理](/external/trino-agent/)。

## Apache Hadoop YARN

- YARN 服务插件：可连接单个 ResourceManager 或高可用的一对，支持简单登录或 Kerberos，查询队列与应用名称；见 [Apache Hadoop YARN](/plugins/yarn/)。
- ResourceManager 中的授权提供者：按策略决定提交、队列与集群管理权限，并支持客户端地址条件；见 [YARN 代理](/external/yarn-agent/)。

## 策略引擎与代理

- 策略可决定对某一层级中任一资源的访问，也可决定对某资源之下内容的访问，因此列出数据库时会计入用户的表策略。
- 逐请求检查的代理会将一个时间窗口内相同的允许访问合并为一条审计事件，附带次数与最后时间；拒绝访问则立即记录。
- 代理可以用所在系统自己的术语展示其访问策略。

## 文档与发布

- YARN、Hive、Kafka、HBase 与 Trino 的插件和代理文档已提供十一种语言版本。
- README 列出了受支持的组件，以及集成测试验证过的版本。
- CI 在一次 Java 门禁之后只运行变更所需的任务，并拒绝缺少发布日志的标签。

## 问题修复

- 种子数据写入后再准备 PostgreSQL 索引，使计时的 API 调用基于已分析的表。
- ZooKeeper 代理的 jar 测试在打包之后运行。
