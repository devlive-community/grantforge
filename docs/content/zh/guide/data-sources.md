数据源负责组织架构同步，身份源继续负责 OIDC 或 LDAP 登录。两者独立配置，停用数据源不影响 OIDC 登录。

1. 在「访问控制 → 身份源」中配置现有 OpenID Connect 登录。
2. 在「访问控制 → 数据源」中添加钉钉数据源，选择关联的 OIDC 身份源。
3. 填写 CorpId、AppKey、AppSecret 和起始部门 ID（通常为 `1`）。AppSecret 单独加密保存，接口不会返回明文，编辑时留空保留原值。
4. 可挂载到本地部门；同步间隔默认 30 分钟，允许 15–10080 分钟，清空表示只手动同步。
5. 保存后测试连接并执行首次同步。钉钉应用需有部门及员工通讯录读取权限，其授权范围应覆盖所选子树。
6. 用户通过 SSO 登录后，按可信 OIDC 邮箱匹配员工，自动填充部门和主部门。邮箱必须由管理员维护、员工不可自行冒用，并与钉钉邮箱一致。员工邮箱缺失时使用企业邮箱。

登录只访问本地通讯录快照，不请求钉钉。开启 MFA 时，在第二步验证成功后更新归属。首次同步前登录的账号会暂存可信邮箱，同步完成后补关联；本地可编辑的个人资料邮箱不参与匹配。缺失、重复或已被其他账号绑定的邮箱不会建立新绑定。

员工绑定以外部员工 ID 保持稳定，不会因邮箱变更转移到另一个员工。同步覆盖多部门归属；主部门优先保留有效原主部门，否则按稳定部门 ID 顺序选择。本地部门、用户组、岗位和直接角色授权保留。将角色分配给同步部门后，用户按现有授权规则继承角色，调岗会更新权限。

已有组织快照或待关联账号后，关联身份源、企业、应用、起始部门和挂载位置固定。同步部门与归属只读，不能从用户或组织管理中手工覆盖。消失的部门保留以保护已有授权；员工离开授权通讯录后移除该数据源管理的归属，不自动停用账号。拥有同步部门的数据源不能直接删除，可改为停用。

同步获取完整分页后再原子应用。读取失败、层级异常或授权范围变化时保留上次成功快照，管理员可通过同步摘要、异常列表和审计记录检查结果。授权范围变化需先恢复原批准范围再同步。

当前使用[钉钉官方服务端 SDK](https://open.dingtalk.com/document/development/download-the-server-side-sdk)，没有自行实现 HTTP 调用。供应商适配器输出统一部门和员工快照，后续可增加飞书适配器，复用相同同步、绑定和权限更新逻辑。
