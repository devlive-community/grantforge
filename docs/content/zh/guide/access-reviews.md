**访问控制 → 权限复核**：定期复核谁持有哪些角色，复核人逐项决定保留或撤销，本轮完成时移除被撤销的分配。

![权限复核](/screenshots/access-reviews.png)

## 复核计划

| 设置 | 说明 |
| --- | --- |
| 名称、说明 | 例如“财务角色季度复核” |
| 角色 | 要复核的角色，每轮会列出它们当前的全部分配 |
| 每轮时长 | 1–90 天，到期自动完成本轮 |
| 重复间隔 | 留空只手动开始；否则按间隔自动开始下一轮 |
| 未复核的项 | 本轮结束时没有决定的项：**保留**或**撤销** |
| 启用 | 只影响是否按计划自动开始 |

## 一轮复核

1. 点击 **立即开始**，或等计划自动开始。GrantForge 为每个分配生成一个复核项（系统账号的系统角色除外）。
2. 复核人在本轮中逐项或批量选择 **保留** 或 **撤销**，撤销可以填写说明；决定可以在本轮结束前撤回。
3. 不能复核自己通过直接分配、用户组、部门或岗位获得的角色。
4. 管理员可以 **完成本轮**（应用全部决定，未决定的按计划设置处理），也可以 **取消本轮**（不做任何改动）。到期未完成的轮次会自动完成。

被撤销的分配在本轮完成时删除。每一步都记录在审计日志中，适合作为内控审计的留痕。
