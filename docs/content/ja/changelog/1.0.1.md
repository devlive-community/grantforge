> これは再構築前の 1.x バージョン（当時の名前は AuthX）です。1.x からアップグレードする場合は [アップグレードと旧バージョンの移行](/ja/deploy/upgrade/) を参照してください。

## 修正

- 新規作成時に明確なヘルプメッセージが表示されない問題を修正しました。
- メニュー管理で分類を選択したあとページングが使えない問題を修正しました。
- メニューを作成するときにインターフェースタイプを選択しても、親メニューのタイプが選択したタイプに応じて変わらない問題を修正しました。
- メニュー作成ページのセレクトボックスがテーマと調和しない問題を修正しました。
- ページの国際化が不完全な問題を修正しました。
- 左メニューから単一メニューへジャンプできない問題を修正しました。
- システムのインターフェースに追加したパスアドレスを権限付与できず、`this is not active token` というメッセージが表示される問題を修正しました。

## 新機能

- 監査ログのタイプ
- ユーザー権限の割り当て機能
- 監査ログ
- ユーザー管理
