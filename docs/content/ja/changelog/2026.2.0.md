2026.2.0 は 2026.1.0 の外部システム権限を Apache Hive、Apache Kafka、Apache HBase、Trino、Apache Hadoop YARN に拡張します。各システムにはサービスプラグインと、ポリシーを適用するエージェントが含まれます。変更の全体は [GitHub の比較](https://github.com/devlive-community/grantforge/compare/v2026.1.0...v2026.2.0) を参照してください。

## Apache Hive

- Hive サービスプラグイン：データベース、テーブル、列、UDF の参照。パスワードまたは Kerberos でサインイン；[Apache Hive](/ja/plugins/hive/) を参照。
- HiveServer2 エージェント：すべての文を認可し、`SHOW` の結果を絞り込み、列をマスクし、行をフィルタリング；[Hive エージェント](/ja/external/hive-agent/) を参照。
- 一時 UDF はグローバル範囲では `tempudfadmin` にのみ付与されます。利用者が指定したコードを実行するため、Apache Ranger と同じ扱いです。

## Apache Kafka

- Kafka サービスプラグイン：トピック、コンシューマーグループ、トランザクション ID、ユーザーの参照。PLAIN、SCRAM、または Kerberos で、平文または TLS を使用；[Apache Kafka](/ja/plugins/kafka/) を参照。
- ブローカーとコントローラーの認可エージェント：すべてのリクエストを確認し、ポリシーを読み取り専用の ACL として表示し、繰り返しのアクセスを 1 件の監査イベントにまとめます；[Kafka エージェント](/ja/external/kafka-agent/) を参照。

## Apache HBase

- HBase サービスプラグイン：ネームスペース、テーブル、カラムファミリーの参照。ZooKeeper またはブートストラップサーバー経由で、単純認証または Kerberos；[Apache HBase](/ja/plugins/hbase/) を参照。
- マスターとリージョンサーバーのコプロセッサー：すべての範囲で操作、読み取り、書き込みを確認し、利用者が読めるカラムのみを返し、利用できない内容は隠します；[HBase エージェント](/ja/external/hbase-agent/) を参照。

## Trino

- Trino サービスプラグイン：カタログ、スキーマ、テーブル、列、セッションプロパティの参照。パスワード、JSON Web Token、または TLS 上の Kerberos でサインイン；[Trino](/ja/plugins/trino/) を参照。
- 2 種類のシステムアクセス制御：Trino 470 から 478 向けと、479 以降向け。クエリを確認し、利用者が使える対象のみを一覧し、行をフィルタリングし、列をマスクします。後者はテーブルブランチとビューの更新も確認します；[Trino エージェント](/ja/external/trino-agent/) を参照。

## Apache Hadoop YARN

- YARN サービスプラグイン：1 台の ResourceManager または高可用性のペアに接続し、単純認証または Kerberos でキューとアプリケーション名を参照；[Apache Hadoop YARN](/ja/plugins/yarn/) を参照。
- ResourceManager 内の認可プロバイダー：提出、キュー、クラスター管理の権限をポリシーで判定し、クライアントアドレスの条件を扱います；[YARN エージェント](/ja/external/yarn-agent/) を参照。

## ポリシーエンジンとエージェント

- ポリシーは、階層内の任意のリソースへのアクセス、およびリソースの下位にある内容へのアクセスを判定できます。そのためデータベースを一覧すると、利用者のテーブルポリシーも計算に含まれます。
- すべてのリクエストを確認するエージェントは、一定時間内に同一で許可されたアクセスを、回数と最後の時刻を付けた 1 件の監査イベントにまとめます。拒否されたアクセスはすぐに記録されます。
- エージェントは、そのシステム自身の用語でアクセスポリシーを表示できます。

## 修正

- シードデータの投入後に PostgreSQL のインデックスを準備するため、計測対象の API 呼び出しは分析済みのテーブルで動作します。
- ZooKeeper エージェントの jar テストは、パッケージング後に実行されます。
