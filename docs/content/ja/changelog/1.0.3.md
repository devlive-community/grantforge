> [!NOTE]
> これは再構築前の 1.x バージョン（当時の名前は AuthX）です。1.x からアップグレードする場合は [アップグレードと旧バージョンの移行](/ja/deploy/upgrade/) を参照してください。

## 修正

- メニューのヘルプメッセージがメニューと一致しない問題を修正しました。
- ページングのデータがページの幅を超える問題を修正しました。
- 新しいユーザーを作成するときに反応しない問題を修正しました。
- コンパイルエラーを修正しました。
- 左側のダッシュボード機能が使えず、ページが真っ白に表示される問題を修正しました。

## 新機能

- JSON ユーティリティ機能を追加しました。
- ダッシュボードのユーザー/ログデータを集計する統計モジュールを追加しました。
