> [!NOTE]
> これは再構築前の 1.x バージョン（当時の名前は AuthX）です。1.x からアップグレードする場合は [アップグレードと旧バージョンの移行](/ja/deploy/upgrade/) を参照してください。

## 修正

- 左メニューが完全に表示されない問題を修正しました。
- JSON データのフォーマット/圧縮時に右側のエディターの内容がクリアされない問題を修正しました。
- メニューが再帰的な方式でカプセル化されるように変更しました。
- 2 階層のメニューにアイコンが表示されない問題を修正しました。

## 新機能

- 後続の機能拡張のために、ユーザーに systemed、locked、email フィールドを追加しました。
- カスタムヘッダー情報への対応を追加しました。
- ヘッダー管理ページの動的ヘッダーに対応しました。
- 動的ヘッダーのページング機能に対応しました。
- JSON を CSV に変換するツールを追加しました。
