2026.1.0 は 2026.0.0 の外部システム権限を HDFS、ZooKeeper、MySQL に広げ、それを適用するエージェントを提供し、コンソールとドキュメントを 11 言語に対応させました。すべての変更は [GitHub の比較](https://github.com/devlive-community/grantforge/compare/v2026.0.0...v2026.1.0)を参照してください。

## Apache Hadoop HDFS

- Hadoop 2.7、2.10、3.2、3.3、3.4、3.5 向けのバージョン別 NameNode エージェントと共通のネイティブモジュール。[HDFS NameNode エージェント](/ja/external/hdfs-agent/)を参照してください。
- すべての Hadoop 系列での Kerberos、複数レルムにまたがるクラスター、検索の間で保持されるサインイン。`swebhdfs` はサービスごとに信頼します。
- Hadoop 2.10 から 3.5 まで、Kerberos クラスターと自動 HA フェイルオーバーで検証済みです。
- エージェントは Hadoop のメトリクスで判断を報告し、適用するポリシースナップショットを固定します。

## Apache ZooKeeper

- TLS セッションとページ単位の znode 検索に対応した ZooKeeper サービスプラグイン。
- サービスのポリシーでマーカー ACL を判定するサーバー側エージェント。[ZooKeeper エージェント](/ja/external/zookeeper-agent/)を参照してください。

## MySQL

- データベース・テーブル・列の検索と、アクセス・マスキング・行フィルターのポリシーを提供する MySQL サービスプラグイン。[MySQL](/ja/plugins/mysql/) を参照してください。
- 文を列単位までチェックし、値をマスクして行をフィルターする MySQL プロキシエージェント。[MySQL プロキシエージェント](/ja/external/mysql-agent/)を参照してください。

## プラグインとポリシー

- エージェントがマスキングと行フィルターのポリシーを評価します。
- ポリシーエディターでサービスのディレクトリを参照してパスを選べます。
- 検索が失敗すると、接続不可、サインイン拒否、権限不足などの理由を示します。
- プラグインを無効にする前に、影響を受けるものを表示します。
- 製品プラグインはドキュメントに専用のセクションがあります。

## コンソール

- 11 のインターフェース言語：簡体字・繁体字中国語、英語、日本語、韓国語、ロシア語、ドイツ語、フランス語、スペイン語、ブラジルポルトガル語、イタリア語。一覧と初期設定ページで選べます。
- 2 段階サインインは QR コードの読み取りで設定し、サインインフォームはサインインできるディレクトリを表示します。
- アカウントページは独自のアドレスを持つタブに分かれ、監査ログと API カタログはすべての一覧と同じページャーを使います。
- 行の操作はツールチップ付きのアイコンボタンになり、ダイアログは双方向にアニメーションして背景クリックを無視し、日付はカレンダーピッカーを使い、リソースツリーを検索できます。
- フォームの検証は、エラーのあるすべてのフィールドを横のヒントで示します。

## ドキュメント

- ドキュメントサイトも同じ 11 言語で公開され、ハングルとキリル文字の単語を検索できます。

## 修正

- MySQL：エージェントの SLF4J バインディングがサーバーのロガーに入らなくなり、ID マッピングをマップとして宣言しました。
- ZooKeeper：セキュリティ勧告を解消する Netty の更新と、強化された TLS セッション。
- 失敗したサービス検索はクライアントエラーとして報告され、組み込みプラグインは製品バージョンを報告します。
- ダイアログ、検証ヒント、スクロール、データサービスフォームに関するコンソールの多数の修正。
