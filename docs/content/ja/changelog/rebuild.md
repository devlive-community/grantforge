2026.0.0 は 1.x（AuthX）を置き換える完全な再構築です。もはやバックオフィスのテンプレートではなく、独立してデプロイされるアイデンティティと権限のプラットフォームです。1.x のアカウント、ロール、メニューはインポートできます。[アップグレードと旧バージョンの移行](/ja/deploy/upgrade/) を参照してください。

## プラットフォーム

- Spring Boot 4、Java 17 ランタイム。1 つのリリースパッケージにサーバーとコンソールの両方が含まれ、あわせて Docker イメージ、Compose、Helm Chart も提供します。
- H2、PostgreSQL、MySQL、MariaDB、Oracle、SQL Server をサポートします。移行は Liquibase が管理し、すべてのコミットが 9 つのデータベースバージョンでテストされます。
- 初回起動時の初期化ウィザードが、サービスログ内のワンタイムトークンでプラットフォーム管理者を作成します。
- クラスターデプロイ。セッションはデータベースに保存し、ID は時間順に並ぶ TSID です。
- 完全に新しくなったコンソール。Vue 3、Tailwind CSS、ライトとダークのテーマ、日本語と英語に対応します。

## アイデンティティと組織

- マルチテナンシー。テナントごとにアカウント、組織、権限付与が完全に分離されます。
- ユーザー、部門ツリー、ユーザーグループ、職位、CSV の一括インポート・エクスポート。
- Argon2id パスワード、設定可能なパスワードポリシーとロック、セッション管理、TOTP 二段階認証とリカバリコード、センシティブな操作の再認証。
- LDAP / Active Directory と OIDC のアイデンティティソース。同期と連合ログインに対応します。

## 権限付与

- リソースカタログ。モジュール、メニュー、ページ、タブ、ボタン、API、データエンティティとフィールド、およびそれらの間の依存関係をまとめたものです。コンソール自身のページ、ボタン、API もカタログに含まれ、同じ権限付与を受けます。
- ロールと権限付与。許可と拒否、継承、ユーザー/ユーザーグループ/部門/職位による割り当て、有効期間。
- データ権限。組織の範囲または構造化された条件によって、参照できるデータ行を制限します。
- フィールド権限。ロールごとにフィールドを非表示、マスク、または読み取り専用にします。
- 権限の説明、ユーザーごとのシミュレーション、完全な監査ログ、そして壊れた設定の検査。

## ガバナンス

- 職務分離。相互に排他的なロールは、割り当て、継承、申請の際に拒否され、すでに存在する衝突も発見できます。
- 権限申請。ユーザーが申請できるロールを申請し、承認者が承認すると一定の時間だけ有効になり、期限が来ると自動的に取り消されます。
- 定期的な権限確認。

## アプリケーション連携

- OAuth 2.1 / OpenID Connect 認可サーバーを内蔵。認可コード + PKCE、クライアントクレデンシャル、リフレッシュトークンのローテーション、署名鍵のローテーション。
- バージョンと ETag を備えた、権限照会のためのオープン API。
- 実行可能なサンプルアプリケーションが付属する Spring Boot Starter と JavaScript SDK。

## 外部システムの権限

- プラグイン化されたサービスタイプ。プラグインがリソース階層、アクセスタイプ、マスク、データ行のフィルタリングを定義し、各プラグインは独立して読み込まれます。
- 汎用ポリシーエディター、Ed25519 署名付きのポリシースナップショット、エージェントのハートビートとアクセス監査。
- サンプルプラグイン、HDFS サービスタイプ、Hadoop 3.5.0 NameNode エージェント。Hive プラグインと他の Hadoop バージョンのエージェントは開発中です。

## 品質

- 100 万アカウント規模の性能ベンチマークが毎晩実行され、上限を超えると失敗します。
- 静的解析（NullAway、Error Prone、Checkstyle、PMD、SpotBugs、ArchUnit）、カバレッジの基準、フルスタックのブラウザテスト。
- ドキュメントサイトは Next.js と Tailwind CSS で作り直されました。
