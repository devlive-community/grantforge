**プラットフォーム管理 → テナント管理**：各テナントは互いに分離された組織であり、独自のユーザーと権限を持ちます。プラットフォームテナントはプラットフォーム管理者を置くテナントであるため、無効化はできません。

![テナント管理](/screenshots/tenants.png)

## テナントの作成

テナントコード、名前、およびこのテナントの最初の管理者のユーザー名、表示名、パスワードを入力します。最初の管理者はこのテナントの「テナント管理者」システムロールを保持し、初回ログイン時にパスワードを変更する必要があります。ユーザー名はプラットフォーム全体で一意です。

## 無効化と有効化

テナントを無効化すると、そのテナントのすべてのアカウントは直ちにログアウトし、ログインできなくなります。発行済みのアプリケーショントークンもこれ以降は更新されません。データは削除されず、再度有効化すれば復元されます。

## プラットフォームテナント

プラットフォームテナントは初期化時に作成される最初のテナントです。このテナントの管理者はすべてのテナント、[リソースカタログと API カタログ](/ja/guide/catalog/)、認可サーバー、プラグインを管理できます。業務アプリケーションとそのリソースはプラットフォーム全体で共有され、各テナントは自分のロールでこれらのリソースに権限を付与します。
