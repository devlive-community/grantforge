フィールド権限は、ロールの保持者が各制御フィールドをどのように**参照・変更**できるかを決定します。ロールの行で **フィールド権限** をクリックして設定します。

![フィールド権限](/screenshots/role-fields.png)

## 参照方式

| 方式 | 効果 |
| --- | --- |
| 表示 | 元の値を表示 |
| マスク | マスク方式に応じて値を一部隠します。メールアドレス（先頭の文字とドメインを保持）、電話番号（138\*\*\*5678）、身分証明書番号（先頭 6 桁と末尾 4 桁を保持）、先頭と末尾の文字を保持、全体を隠す |
| 非表示 | このフィールドを一切返さず、リストにその列を表示しません |

## 変更方式

| 方式 | 効果 |
| --- | --- |
| 変更可能 | 入力および変更できます |
| 読み取り専用 | フォーム内で無効化されます。API を直接呼び出して変更すると、どのフィールドかを指摘するエラーが返されます |

## 結合ルール

- 未設定のフィールドは、保持者の他のロールが決定します。どのロールでも設定されていない場合、そのフィールドは表示され、変更できます。
- 複数のロールが同じフィールドを設定する場合、**最も緩い**設定が適用されます（表示 > マスク > 非表示、変更可能 > 読み取り専用）。
- 検索とエクスポートもフィールド権限に従います。非表示のフィールドは検索に使えず、エクスポート時はルールに従って非表示またはマスクされます。

## 制御フィールド

制御フィールドはサーバー側のコードで宣言します（現在はユーザーのメールアドレスと最終ログイン時刻）。**プラットフォーム管理 → リソースカタログ** に、そのフィールドがどのインターフェースに現れるかが表示されます。ビジネスアプリケーションのフィールド制御はアプリケーション自身で実装でき、ルールも同じくオープン API から取得します。
