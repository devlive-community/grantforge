**アクセス制御 → 定期的な権限確認** では、誰がどのロールを保持しているかを定期的に確認します。確認者が項目ごとに維持または取り消しを決定し、取り消された割り当てはそのラウンドが終了した時点で削除されます。

![定期的な権限確認](/screenshots/access-reviews.png)

## 確認計画

| 設定 | 説明 |
| --- | --- |
| 名前、説明 | 例えば「財務ロールの四半期確認」 |
| ロール | 確認対象のロールです。各ラウンドではこれらのロールの現在の割り当てがすべて列挙されます |
| ラウンドの長さ | 1〜90 日です。期間が終了するとそのラウンドは自動的に完了します |
| 繰り返し間隔 | 空にすると手動でのみ開始し、値を入れるとその間隔ごとに次のラウンドが自動的に開始されます |
| 確認しなかった項目 | ラウンドの終了時に決定しなかった項目の扱いです。**維持** または **取り消し** |
| 有効 | 計画どおりに自動開始するかどうかにのみ影響します |

## 1 回の確認

1. **今すぐ開始** をクリックするか、計画が自動的に開始するまで待ちます。GrantForge は割り当てごとに確認項目を 1 件ずつ作成します（システムアカウントのシステムロールは除きます）。
2. 確認者はこのラウンドの間、項目ごとにまたは一括で **維持** または **取り消し** を選択します。取り消しには説明を入力でき、決定はこのラウンドが終了する前に撤回できます。
3. 直接の割り当て、ユーザーグループ、部門、または職位を通じて得た自分のロールは確認できません。
4. 管理者は **ラウンドの完了**（すべての決定を適用し、決定しなかった項目は計画の設定に従って処理）または **ラウンドの取り消し**（まったく変更を行わない）を行えます。期限内に終了しなかったラウンドは自動的に完了します。

取り消された割り当ては、このラウンドが完了した時点で削除されます。すべての手順が監査ログに記録されるため、内部統制の監査の痕跡として利用するのに適しています。
