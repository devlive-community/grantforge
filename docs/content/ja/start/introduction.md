GrantForge はオープンソース（MIT）の統合権限プラットフォームです。「誰が何をでき、どのデータを見られるか」を一元的に管理します。コンソールでユーザーと組織を管理し、ロールを定義し、ロールにメニュー、ボタン、API、データ行、フィールドの権限を付与します。アプリケーションは OAuth 2.1 / OpenID Connect でユーザーをログインさせ、オープン API または SDK で権限を判定します。

![GrantForge コンソール](/screenshots/dashboard.png)

## どのような課題を解決するか

システムがある規模に達すると、権限はあちこちに散らばりがちです。メニューはフロントエンドの設定に置かれ、インターフェースはそれぞれアノテーションで検証され、データの範囲は SQL に手書きした条件に依存しています。退職や異動の際に、ある人に何ができて何ができないのか、誰も正確に答えられません。GrantForge はこれらを 1 つのモデルに統合します。

- **一度定義すればどこでも効く**：コンソールのページ、ボタン、REST インターフェース、データエンティティとフィールドはすべて「リソース」です。ロールがリソースに権限を付与すると、その 1 つの権限付与がフロントエンドの表示・非表示とバックエンドのブロックの両方を制御します。
- **目に見える権限**：「なぜこのユーザーはこのページを見られるのか」「このロールを変更すると誰に影響するのか」にいつでも答えられます。権限付与の変更にはプレビューと監査の記録があります。
- **ガバナンス要件への対応**：職務分離、期限付きの権限申請、定期的な確認、二段階認証により、等級保護と内部統制監査の一般的な要件を満たします。
- **標準プロトコルとの連携**：アプリケーションが独自のユーザー機構を内蔵する必要はありません。OIDC でログインし、アクセストークンで権限を照会すれば済みます。

## 機能一覧

| 領域 | 機能 |
| --- | --- |
| アイデンティティと組織 | マルチテナンシー、部門ツリー、ユーザーグループ、職位、CSV の一括インポート・エクスポート、LDAP/AD ログインと同期、OIDC 連合ログイン |
| アカウントセキュリティ | セッション管理、パスワードポリシーとロックアウト、TOTP 二段階認証とリカバリコード、重要な操作の再検証 |
| 機能の権限付与 | リソースカタログ（モジュール、メニュー、ページ、タブ、ボタン、API）、ロール継承、権限付与マトリックス、影響分析 |
| データ権限 | 条件に応じて表示される行を制限（本人、所属部門およびその配下、指定部門、カスタム条件）し、読み取りと書き込みを分けて制御 |
| フィールド権限 | フィールドの非表示、マスク（メールアドレス、電話番号、証明書番号など）、読み取り専用 |
| 説明可能性と監査 | 権限の説明、権限付与のシミュレーション、監査ログの照会とエクスポート |
| ガバナンス | 職務分離の制約、権限申請と承認、定期的な権限の確認 |
| アプリケーション連携 | OAuth 2.1 / OIDC 認可サーバー、権限照会用のオープン API、Java（Spring Boot）と JavaScript SDK |
| 外部システム | プラグイン方式のサービスタイプとポリシーエンジン（Apache Ranger に類似）、データサービス、アクセスポリシーとエージェント |
| 提供 | 単一のリリースパッケージ、Docker イメージ、Compose のサンプル、Helm Chart、H2、PostgreSQL、MySQL、MariaDB、Oracle、SQL Server |

## 一般的な代替手段との違い

> [!NOTE]
> GrantForge は RBAC だけを行うライブラリでも、シングルサインオンだけを行う IdP でもありません。アイデンティティ、権限付与、ガバナンスを 1 つのモデルにまとめ、すべての権限付与を説明できるようにしています。

- **コードに権限を手書きする場合と比べて**：権限のルールはコンソールで管理するため、権限付与を変更してもアプリケーションを再デプロイする必要はありません。付与する前に影響範囲を確認でき、付与した後には監査の記録が残ります。
- **認証だけを行う IdP（Keycloak など）と比べて**：GrantForge はボタン、データ行、フィールドまで細かく制御できる権限付与モデルと、職務分離や確認のためのガバナンス機能を備えています。同時に IdP としても機能し、既存の LDAP や OIDC をアイデンティティソースとして連携できます。
- **Apache Ranger と比べて**：GrantForge は外部データシステムの権限を管理するため、Ranger のサービスタイプ、ポリシー、エージェントのアーキテクチャを参考にしています。一方で GrantForge は、まず第一に業務アプリケーションのための権限プラットフォームです。
