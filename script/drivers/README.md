# JDBC drivers

Jars in this folder join the server's class path (`bin/startup.sh`, `bin/debug.sh`). GrantForge bundles the drivers of
H2, PostgreSQL, MariaDB, Oracle and SQL Server; MySQL Connector/J is GPL and is not redistributed, so MySQL users put
`mysql-connector-j-<version>.jar` here.
